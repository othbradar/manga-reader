# 拷贝漫画阅读器

`拷贝漫画阅读器` 是使用 Flutter 编写的 Android、iPhone、iPad 和 macOS
漫画库管理与阅读应用。当前版本为 **0.4.2+27**。

它直接使用桌面端整理后的“漫画文件夹 + 章节 ZIP + SQLite 总索引”格式，
可以在电脑、Android、iPhone 和 iPad 之间搬运同一套漫画库，不需要转换成
应用私有格式，也不使用 JSON 文件保存索引。

## 设计原则

- 共享漫画内容只认 `拷贝漫画总索引.db`、漫画目录、封面图片和章节 ZIP。
- 阅读进度、最近观看、登录状态、收藏缓存、下载任务和界面设置保存在应用本机，
  不混入共享漫画索引。
- 能匿名完成的搜索、详情、章节和图片请求不携带会员令牌。
- 点未下载章节是在线阅读并写入可清理缓存；只有在章节选择页确认后才生成正式
  ZIP 并写入下载记录。
- 外置漫画库的原始 SQLite 索引不直接打开写入。应用首次选择外置库时把索引复制
  到本机作为工作索引，外置盘保存漫画文件和原始索引。

## 主要功能

### 漫画库

- 自动识别包含 `拷贝漫画总索引.db` 的漫画目录。
- 显示漫画名称、作者和本地封面。
- 简体、繁体漫画名和作者双向搜索。
- 按原始顺序或标题首字母排序。
- 按“动漫之家独有”“拷贝漫画独有”“两边都有”等来源筛选。
- 从漫画文件夹和章节 ZIP 补建缺失索引。
- 选择手机目录或 USB 外置盘作为漫画库，并可恢复默认目录。

### 拷贝漫画

- 在线搜索、漫画详情、章节目录和收藏同步。
- 国内、海外和自动线路，支持动态节点发现、测速、故障切换和手动节点。
- 账号 API 与内容 API 可独立选择节点。
- 登录令牌只用于会员资料和收藏等必须登录的接口。
- 批量扫描所有能对应拷贝漫画的本地项目，缓存简介并找出缺章。
- 批量扫描失败自动重试，结果页可再次重试全部失败项目。
- 扫描并发和章节图片下载并发都可在 1–10 之间设置。

### 阅读与下载

- 已下载章节读取本地 ZIP。
- 未下载章节直接匿名在线阅读，图片按页写入应用缓存，不生成 ZIP。
- 独立章节下载选择页，支持全选缺章、取消全选和按分组勾选。
- 每个章节或单行本保存为一个 ZIP，兼容桌面下载器的命名规则。
- 下载进度、全局暂停、全部继续、清空任务和失败重试。
- 单页网络失败会自动退避重试；401/403/404 或连续失败时会刷新章节
  图片地址，已落盘页面不会重复下载。
- 单页重试耗尽后整章会按 10/30/60 秒后台补下；等待期间不阻塞其他章节。
- 图片 CDN 使用独立连接池，不携带内容 API 签名、设备头或账号 Token。
- 应用意外退出后把进行中的任务恢复成安全暂停状态。
- 默认上下连续无间距阅读，也支持左右单页。
- 沉浸阅读、轻点显示工具栏、双击缩放、按钮缩放和双指缩放。
- 放大后单指可自由二维拖动，并能在连续模式中继续跨页滚动。
- 阅读位置和最近观看记录保存在本机 SQLite。

### 界面

- 手机使用底部导航，平板和 Mac 宽屏自动使用侧边导航。
- 白色、米白色、浅灰色和深灰色主题。
- 深色模式支持跟随系统、始终浅色和始终深色。
- 所有较长说明集中在“我的 → 设置与说明”。

## 漫画库格式

```text
漫画/
├── 拷贝漫画总索引.db
├── 拷贝漫画阅读器应用数据.db          可选的跨设备应用数据备份
├── 漫画名 - 作者/
│   ├── 漫画名 - 作者 - 汇总.jpg
│   ├── 漫画名 - 作者 - 第001话.zip
│   ├── 漫画名 - 作者 - 第002话.zip
│   └── ...
└── 另一部漫画 - 作者/
    └── ...
```

章节 ZIP 内的图片按自然数顺序排列。应用可识别 JPEG、PNG、WebP、GIF、BMP
和 JPEG XL 等常用图片扩展名。

默认漫画库位置：

- Android：
  `/storage/emulated/0/Android/data/com.othbradar.copymangareader/files/漫画`
- iPhone / iPad：
  “文件”App →“我的 iPhone / iPad”→“拷贝漫画阅读器”→`漫画`
- macOS 沙盒默认目录：
  `~/Library/Containers/com.othbradar.copymangareader.macos/Data/Documents/漫画`
  （日常使用建议在设置中选择用户自己的漫画库目录）

## 两个 SQLite 数据库

| 数据库 | 作用 | 是否随漫画库搬运 |
| --- | --- | --- |
| `拷贝漫画总索引.db` | 漫画、作者、来源、章节分组、章节 ZIP 相对路径和共享下载索引 | 是 |
| `copy_manga_reader_local.db` | 阅读进度、最近观看、收藏缓存、详情缓存、下载任务、简繁搜索索引和设置 | 默认只留在当前设备 |
| `拷贝漫画阅读器应用数据.db` | 由设置页显式导出的可携式应用数据快照，导入时映射到新设备的当前漫画库 | 是，可选 |

外置库首次选择时，`拷贝漫画总索引.db` 会复制到应用支持目录成为本机工作
索引。这样拔盘或系统文件授权变化不会损坏外置盘中的原始索引。

应用数据迁移不会改共享总索引。登录令牌、密码和 Android/iOS/macOS 的系统目录
授权不会写入可携式备份，需要在新设备重新选择目录并登录。

## 快速开始

1. 安装 APK、签名后的 IPA，或打开 macOS Release `.app`。
2. 将完整 `漫画` 文件夹复制到默认位置；也可以先不复制，在设置中直接选择
   USB 外置盘上的漫画目录。
3. 启动应用，等待 SQLite 索引和简繁搜索索引载入。
4. 在“漫画库”打开本地漫画；在“搜索”页查找在线漫画。
5. 点未下载章节可直接在线阅读。需要永久保存时，点详情页的下载按钮进入章节
   选择页。
6. 登录后可在“收藏”页同步拷贝漫画收藏。

## 开发与验证

```bash
flutter pub get
dart analyze --fatal-infos
flutter test --concurrency=1
flutter build apk --release --no-pub
flutter build ios --release --no-codesign --no-pub
flutter build macos --release --no-pub
```

发布前必须至少通过严格静态检查和完整测试。真实漫画库与真实 ZIP 测试默认跳过，
可通过环境变量显式指定只读样本：

```bash
COPYMANGA_REAL_LIBRARY=/absolute/path/拷贝漫画总索引.db \
  flutter test test/real_library_test.dart

COPYMANGA_REAL_ZIP=/absolute/path/chapter.zip \
  flutter test test/real_zip_test.dart
```

## 第三方数据与发布产物

`assets/opencc` 中的简繁字符映射来自 OpenCC，并保留其 Apache-2.0
许可证文件。

APK、IPA、Flutter 构建缓存、逆向参考 APK 和本机签名材料不提交到 Git。
正式安装包由本地发布流程生成。项目没有在仓库中保存用户账号、密码、会员令牌、
签名证书或私钥。
