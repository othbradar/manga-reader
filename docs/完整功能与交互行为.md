# 完整功能与交互行为

本文不是简要宣传页，而是当前 `0.3.16+24` 的功能规格。它按“用户做了什么、
应用读取什么、应用写入哪里、成功后看到什么、失败后保留什么”的顺序描述每项功能，
供日常使用、回归测试和后续修改界面时核对。

源码级类和函数对应关系见[源码模块与函数索引](源码模块与函数索引.md)。

## 1. 应用启动

### 1.1 初始化顺序

应用启动后按以下顺序初始化：

1. 取得 Android 或 iOS 的设备标识，供拷贝漫画协议请求头使用。
2. 打开应用自己的 `copy_manga_reader_local.db`。
3. 恢复主题颜色和深色模式。
4. 从本机数据库载入最近观看。
5. 载入内置 OpenCC 简繁转换字典。
6. 恢复上次选择的漫画库；如果没有记录则打开默认漫画库。
7. 打开漫画库总索引，校验四张核心表，并建立本机搜索索引。
8. 恢复内容线路、内容 API 节点、账号 API 节点和自动/手动模式。
9. 从系统安全存储恢复登录令牌，并用账号资料接口验证令牌。
10. 读取该漫画库对应的收藏缓存和下载任务。

这些步骤有依赖关系。漫画库必须先打开，收藏和下载任务才能按当前
`library_key` 隔离加载；OpenCC 字典必须先载入，本地简繁搜索索引才会完整。

### 1.2 启动时的界面状态

- 漫画库尚未打开时显示圆形进度条。
- 复制外置索引时额外显示“正在把外置索引复制到本机 N%”。
- 漫画库成功打开后显示漫画封面网格。
- 打开失败时显示原始原因和“重试”按钮。
- 重试会重新执行漫画库定位、索引打开、搜索索引刷新和列表加载。
- 登录、收藏或节点发现失败不会阻止本地漫画库打开。

### 1.3 启动时不会做的事

- 不会自动扫描全部远端漫画更新。
- 不会自动下载缺章。
- 不会把登录令牌写进漫画库总索引。
- 不会覆盖外置盘上的 SQLite。
- 不会删除漫画 ZIP、封面或缓存。

## 2. 一级导航

手机窄屏使用底部导航栏，宽度不小于 760 逻辑像素时使用左侧导航栏。四个一级页面
始终保持在 `IndexedStack` 中，切换页面不会销毁已经输入的搜索文字或当前列表状态。

| 页面 | 主要用途 | 是否需要登录 |
| --- | --- | --- |
| 漫画库 | 浏览本地库、搜索、筛选、进入详情、管理下载和批量补缺 | 否 |
| 搜索 | 匿名搜索拷贝漫画并在线查看详情 | 否 |
| 收藏 | 查看和同步拷贝漫画账号收藏 | 是 |
| 我的 | 登录/退出、最近观看、漫画数量、进入设置 | 登录仅用于账号功能 |

## 3. 漫画库页面

### 3.1 漫画卡片

每张卡片显示本地或网络封面以及漫画名。封面选择顺序为：

1. `cover_relative_path` 指向且确实存在的本地图片。
2. 漫画详情中的网络 `cover_url`。
3. 以漫画名生成的占位封面。

点击卡片进入漫画详情页。卡片的稳定标识优先使用 `comic_uuid`，其次是
`path_word`，最后才是“标题 + 作者”，以免搜索结果重绘时打开错漫画。

### 3.2 本地搜索框

- 搜索对象是当前漫画库中的漫画名和作者，不访问网络。
- 输入后等待 220 毫秒再查询，连续输入会取消上一次等待。
- 原始标题/作者和 OpenCC 归一化标题/作者同时参与匹配。
- 简体关键词可以匹配繁体标题，繁体关键词也可以匹配简体标题。
- 搜索结果出来后列表自动回到顶部。
- 清空搜索框恢复当前来源筛选下的全部漫画。

本地搜索索引位于应用本机 SQLite，而不是共享总索引；因此不会给外置数据库增加
FTS 表或其他应用专用字段。

### 3.3 来源筛选

点击搜索框右侧的调节图标打开筛选面板：

| 选项 | `source_kind` 条件 |
| --- | --- |
| 全部 | 不限制 |
| 动漫之家独有 | `dmzj` |
| 拷贝漫画 | `copy_manga` |
| 二者都有 | `both` |

筛选可以和搜索、排序组合使用。启用非默认筛选或排序后，调节图标显示标记。选择会写入
本机 `local_preferences`，下次启动自动恢复。

### 3.4 排序

- “原先顺序”：按 `library_order` 升序，数值相同时按漫画名。
- “首字母”：优先按 `title_sort_key`；没有排序键时按小写标题；相同键再按原先顺序。
- 切换排序后列表回到顶部。
- 排序只改变显示，不重排目录、不重命名文件，也不改章节顺序。

### 3.5 可拖动进度条

漫画库网格启用常显滚动条，滑块可以直接拖到列表任意位置。轨道本身透明，不显示原先
左侧的细竖线。滚动条只操作界面滚动位置，不写数据库。

### 3.6 下载任务入口

下载图标右上角显示等待或下载中的任务数。点击进入二级“下载任务”页。已完成任务不计入
角标，但仍可在任务列表中保留，直到用户清空任务记录。

### 3.7 漫画库操作菜单

菜单包含：

- “拷贝漫画补缺”：进入批量扫描页面。
- “刷新本地索引”：重新从 SQLite 查询列表；不访问网络，也不扫描文件夹。

## 4. 漫画详情页

### 4.1 打开本地漫画

进入页面时：

1. 如果漫画已有 UUID，先从当前漫画库重新读取最新记录。
2. 读取该漫画全部章节。
3. 按 `group_name` 分组。
4. 每组按数据库返回的章节顺序显示。

详情头显示：

- 漫画名；
- 别名（非空时）；
- 作者，空值显示“未知作者”；
- 连载状态（非空时）；
- “本地已下载章节数 / 总章节数”；
- 已缓存的简介；
- 本地封面或网络封面。

### 4.2 打开在线搜索结果

搜索结果本身可能只有 `path_word` 而没有可靠 UUID。打开时必须先请求
`/api/v3/comic2/{path_word}`，并验证服务端返回的 `path_word` 与点击项完全对应。
解析得到真实 UUID 后才写入漫画索引并进入详情页，防止多个相似名称漫画串页。

### 4.3 更新详情和章节

右上角同步按钮和下拉刷新执行相同操作：

1. 纯本地 `local-` 漫画直接提示没有在线标识。
2. 请求漫画详情并校验 UUID、`path_word`。
3. 更新核心漫画记录中允许更新的在线字段。
4. 把简介、状态、地区、主题、热度等详情缓存到本机数据库。
5. 枚举详情返回的全部章节组。
6. 每组分页请求章节并更新章节索引。
7. 如果本地没有封面，下载封面到漫画目录并记录相对路径。
8. 重新读取并刷新当前页面。

更新在线数据时保留本地目录、封面相对路径、已下载章节路径、来源分类和
`library_order`，不会把本地状态重置为远端状态。

### 4.4 章节分组

- 每个章节组默认展开。
- 标题显示组名，空组名显示“默认”。
- 副标题显示总章节数和已下载数。
- 全组已下载时显示完成图标。
- 存在缺章时显示组级下载按钮。
- 章节有页数时显示页数。
- 本地章节显示播放图标，未下载的在线章节显示云图标。

“卷”“话”“其他系列”等组名完全采用上游返回结果，应用不会擅自把卷和话混在一起。

### 4.5 点击已下载章节

应用根据 `archive_relative_path` 拼出当前漫画库内的绝对路径：

- ZIP 存在：进入本地阅读器。
- 索引有路径但文件不存在：提示重新复制漫画文件或重新下载。
- 点击动作不会重新访问章节图片 API。

### 4.6 点击未下载章节

未下载章节默认进入在线阅读，而不是立即下载：

- 纯本地漫画或缺少在线标识时拒绝在线阅读。
- 在线阅读只把当前阅读到的图片写入应用临时缓存。
- 不生成章节 ZIP。
- 不把章节标记为已下载。
- 退出后仍可由系统清理临时缓存。

### 4.7 正式下载入口

详情页有三类入口：

- “下载全部缺章”：预选全书所有未下载章节。
- 章节组右侧下载按钮：预选该组全部缺章。
- 在章节选择页手动勾选任意缺章。

所有入口最终都进入“选择下载章节”二级页面，不会在点击章节正文时偷偷下载。

## 5. 章节选择下载页

### 5.1 列表范围

页面只列出 `archive_relative_path` 为空的章节。已经下载的章节不会出现，也不能被重复
加入任务。

### 5.2 选择操作

- 顶部实时显示“已选 N / 缺章总数”。
- “全选缺章”选择所有当前未下载章节。
- “取消全选”清空选择。
- 每个章节可单独勾选。
- 章节仍按上游分组，组标题显示该组缺章数。
- 提交期间禁用复选框和提交按钮，避免重复入队。

### 5.3 加入队列

点击底部“加入下载”后：

- 已下载章节跳过。
- 当前任务列表已存在相同 `chapter_uuid` 的章节跳过。
- 新任务状态为 `queued`。
- 页面返回实际新增数量。
- 新增为 0 时提示章节已经在队列中。
- 入队本身不会自动改变全局暂停状态；用户在下载任务页决定开始或继续。

## 6. 下载任务

### 6.1 任务状态

| 状态 | 页面文字 | 含义 |
| --- | --- | --- |
| `queued` | 等待中 | 已入队，等待处理 |
| `downloading` | 下载中 N% | 正在取得章节图片或打包 |
| `paused` | 已暂停 N% | 用户暂停或应用退出后的安全状态 |
| `completed` | 已完成 | ZIP 和章节索引均已落盘 |
| `failed` | 失败 N% | 保留错误，可重试 |

进度按所有页面的综合字节进度计算；通知界面的频率限制为约 250 毫秒一次，单页完成时
强制刷新，避免高并发时因为过多界面重绘造成卡顿。

### 6.2 全局暂停

点击“全局暂停”：

1. 设置暂停标志。
2. 取消当前 Dio 图片请求。
3. 把尚未开始的 `queued` 任务改为 `paused`。
4. 等待正在执行的下载工作器退出。
5. 保留 `.download_tmp/{chapter_uuid}` 中已完整下载的页面。
6. 重新读取任务列表。

暂停不会删除 ZIP、完整页面或任务记录。需要拔外置盘时，应先暂停并等待界面变为
“下载已全局暂停”。

### 6.3 全部继续

点击“全部继续”：

- 把 `paused` 和 `failed` 任务恢复为 `queued`；
- 清除旧错误文字；
- 不删除临时目录；
- 已存在的完整页按序号识别并跳过；
- 从第一个等待任务继续处理。

### 6.4 单项重试

失败或暂停任务右侧显示重试按钮。重试将该任务改为 `queued`、进度重置为 0 并清除
错误。如果全局仍暂停，任务只进入等待状态；如果全局正在运行，则立即进入处理循环。

### 6.5 清空任务

清空按钮会先弹出确认对话框。确认后：

- 先暂停和取消当前请求；
- 等待工作器退出；
- 删除当前漫画库对应的本机任务记录；
- 清空任务列表；
- 不删除已经完成的章节 ZIP；
- 不删除漫画封面；
- 不删除漫画或章节索引；
- 不主动删除未完成临时页。

这是“清空任务记录”，不是“删除已下载漫画”。

### 6.6 应用异常退出后的恢复

下次打开漫画库时，原状态为 `downloading` 的任务会改成 `paused`，错误文字为
“应用上次退出，任务已安全暂停”。应用不会把不完整文件误判为完成章节。

### 6.7 单章节下载流水线

1. 请求章节图片 URL 列表，空列表视为失败。
2. 建立漫画目录和 `.download_tmp/{chapter_uuid}`。
3. 识别临时目录中已经完成的页面。
4. 按设置的 1–10 路并发下载缺失页面。
5. 图片先写为 `.part`，完整落盘后改成真实图片扩展名。
6. 所有页面完成后生成 `章节名.zip.partial`。
7. 打包成功后原子改名为正式 `.zip`。
8. 在共享索引中写入章节相对路径和页数。
9. 如果漫画没有本地封面则缓存封面。
10. 删除该章节临时目录。
11. 把任务标记为 `completed`。

只有第 8 步成功后，章节才算已下载。服务器返回的 `Content-Type` 不可信，图片扩展名
由文件魔数判断，因而可以处理服务器误报 `binary/octet-stream` 的情况。

## 7. 拷贝漫画批量补缺

### 7.1 扫描范围

扫描对象是共享索引中：

- `source_kind = copy_manga` 或 `both`；
- 有非空 `path_word`；
- `path_word` 不是 `local-` 开头。

动漫之家独有且没有拷贝漫画标识的漫画不会发起无意义请求。

### 7.2 开始扫描和重新扫描

首次按钮显示“开始扫描”，有旧结果后显示“重新扫描”。重新扫描会重新请求全部符合条件
的漫画，用于几个月后检查新章节，而不是复用旧扫描结果。

### 7.3 并发与停止

- 扫描并发由设置页控制，范围 1–10，默认 4。
- 工作器共享下一个漫画索引，每部漫画只交给一个工作器。
- “停止”只阻止领取新漫画；已经开始的请求会正常收尾。
- 离开页面会设置停止标志。
- 停止后的已完成结果保留在当前页面，可重新扫描。

### 7.4 单部漫画扫描内容

每部漫画最多自动尝试三次。每次：

1. 取得最新详情；
2. 把简介等详情写入本机详情缓存；
3. 请求全部章节组和分页章节；
4. 与本地 `archive_relative_path` 比较；
5. 生成缺章列表。

批量扫描不会下载封面，避免千部漫画同时产生大量额外图片请求；进入单部详情或正式下载
时再补封面。

### 7.5 结果页

汇总显示：

- 有缺章的漫画数；
- 缺失章节总数；
- 已经取得简介的漫画数；
- 失败漫画数。

结果排序为：成功项在前、缺章多的在前、最后按漫画名；失败项集中在后面。成功项可以
点击进入漫画详情。

### 7.6 重试失败

“重试全部失败项”只重新请求失败漫画：

- 成功结果不重复请求；
- 新结果替换原失败项；
- 仍失败时记录“已尝试 N 次仍失败”和最后原因；
- 结果汇总随重试动态更新。

### 7.7 全部缺章加入下载

点击后把所有成功结果中的缺章批量入队。任务去重仍以 `chapter_uuid` 为准，所以重复点击
不会制造重复下载。加入任务后需要到“漫画库 → 下载任务”点击“全部继续”。

## 8. 在线搜索

### 8.1 搜索请求

- 不需要登录。
- 不发送会员 Token。
- 每页最多取 20 条。
- 先使用用户原始关键词；无结果时再按 OpenCC 产生的简体/繁体变体依次搜索。
- 节点必须返回 `results.list`，HTTP 200 但列表结构缺失也算节点失败。
- 结果缺少标题或 `path_word` 时过滤掉。

### 8.2 点击搜索结果

点击后先锁定页面，避免连续点击产生并发详情跳转。应用请求详情并验证返回的
`path_word`，取得真实 UUID 后缓存漫画和详情，再进入详情页。退出详情页后刷新本地
漫画库，因此刚查看的在线漫画可以按索引规则显示。

## 9. 在线阅读缓存

在线阅读取得章节图片 URL 后，为章节建立：

```text
系统临时目录/
└── copy_manga_online_cache/
    └── <chapter_uuid SHA-256 前24位>/
        └── page_<页码>_<URL哈希>.image
```

- 图片按需下载。
- 当前页前后各 2 页后台预读。
- 同一页正在下载时复用同一个 Future，不会重复请求。
- 文件先写 `.part`，完成后原子改名。
- 缓存文件非空才算有效。
- 单页失败会显示“重试”，重试只清除该页的内存失败状态。
- 在线缓存不写共享漫画库，也不生成 ZIP。

## 10. 阅读器

### 10.1 默认模式和沉浸界面

- 默认是上下连续滚动。
- 进入阅读器立即启用 `immersiveSticky`。
- 默认隐藏顶部栏和底部页码，没有上下黑色工具栏。
- 单击画面显示或隐藏工具栏。
- 退出阅读器恢复系统 `edgeToEdge`。

### 10.2 上下连续阅读

- 所有图片以屏幕宽度连续排列，不人为增加页间黑边。
- 使用两个 Sliver 围绕已保存页建立锚点，恢复进度时不会先跳到列表末尾。
- 上下滚动结束后，以屏幕高度 35% 处所在页面作为当前页。
- 当前页变化 150 毫秒后写入进度，连续滚动会合并频繁写入。
- 图片按当前屏幕像素宽度解码，减少整库和长章节下的内存/滑动压力。
- 前后约两个视口参与滚动缓存。

### 10.3 左右翻页

- 使用 `PageView`，一页一屏。
- 图片使用 `BoxFit.contain`。
- 页面切换立即更新当前页并延迟写入进度。
- 从上下模式切换过来时保持当前页。

### 10.4 放大缩小

支持：

- 双指捏合，范围 1–5 倍；
- 工具栏放大，每次乘 1.5；
- 工具栏缩小，每次除 1.5；
- 双击从 1 倍切换到 2.5 倍；
- 已放大时双击恢复 1 倍；
- 单指斜向拖动，不锁死为水平或垂直方向。

左右模式放大后，单指可以在一张图内同时横向和纵向移动。上下连续模式放大后：

- 水平位移用于查看图片左右区域；
- 垂直位移传给连续列表；
- 因而可以保持放大比例跨页上下滑动；
- 捏合焦点变化也同步修正连续列表位置。

切换阅读方向会先重置缩放，避免上一模式的变换矩阵污染新布局。

### 10.5 阅读进度

- 进度按 `chapter_uuid` 保存，不写漫画库总索引。
- 重新进入同一章节时恢复到合法页码范围内。
- 上下模式恢复时以该页为 Sliver 锚点。
- 左右模式恢复时用该页创建 `PageController`。
- 用户继续阅读后会覆盖旧页码，不会反复强制跳回旧位置。
- 离开阅读器时再排队写入一次最终位置。

### 10.6 图片错误

- 本地 ZIP 读取失败显示页号和具体错误。
- 在线图片失败额外显示“重试”按钮。
- 章节初始化失败显示“章节打开失败”。
- 本地 ZIP 中没有支持的图片会明确提示，而不是显示空白页面。

## 11. ZIP 阅读

打开本地章节时：

1. 为本次阅读建立系统临时目录。
2. 在 Dart Isolate 中解码 ZIP，避免阻塞界面线程。
3. 只保留支持的图片文件。
4. 使用自然数顺序排序，例如 `2.jpg` 在 `10.jpg` 前。
5. 逐页解压成 `page_000000.ext`。
6. 校验解压文件不为空。
7. 阅读器关闭时删除本次临时目录。

原始章节 ZIP 不会被修改。

## 12. 收藏

### 12.1 未登录

收藏页显示登录入口，不会尝试调用收藏接口。

### 12.2 已登录

- 先显示当前漫画库对应的本地收藏缓存。
- “同步收藏”按每页 18 条请求全部收藏。
- 默认排序为远端更新时间倒序。
- 服务端返回空页或达到 `total` 后停止。
- 同步成功后用事务替换本地收藏缓存。
- 同步失败保留上次成功缓存，并在页面显示错误。
- 点击收藏项走和在线搜索相同的详情校验流程。

收藏缓存按 `library_key` 隔离；切换漫画库后会读取该库自己的缓存视图。

## 13. 登录与退出

### 13.1 登录页

- 账号为空或密码为空时不发请求。
- 密码框默认隐藏，可切换显示。
- 提交期间按钮禁用并显示进度。
- 登录使用账号专用国内节点池。
- 密码按当前协议加盐并 Base64 编码。
- 返回 Token 后必须再调用资料接口验证。
- 资料验证失败会立即清除内存 Token，登录不算成功。

### 13.2 登录成功

- Token 和账号名写入 Android Keystore/iOS Keychain 支持的安全存储。
- 明文密码不会写入 SQLite 或安全存储。
- 登录页返回后自动同步收藏。

### 13.3 启动恢复

启动读取安全存储 Token 后调用资料接口：

- 成功：恢复昵称、头像等内存状态。
- 明确 401：自动退出并删除无效 Token。
- 普通网络错误：不把网络故障误判为账号失效。

### 13.4 退出

退出会：

- 清空网络层内存 Token；
- 清空用户名、昵称和头像；
- 删除安全存储中的 Token 与账号名；
- 保留本地漫画、已下载 ZIP 和收藏缓存。

## 14. 我的页面

- 账号卡片显示昵称；没有昵称时显示账号；未登录显示“尚未登录”。
- 头像占位使用显示名首字符。
- 登录状态显示“退出”，未登录显示“登录”。
- “最近观看”显示记录数量和最近一部漫画。
- “漫画库”显示当前加载的漫画总数，不受当前筛选影响。
- “设置与说明”进入设置页。

## 15. 最近观看

- 最多从本机数据库显示最近 100 部漫画。
- 每部漫画只保留一条最近记录；再次阅读会移到最前。
- 副标题显示章节名、页码/总页数以及观看时间。
- 点击记录进入漫画详情，不会自动打开章节，避免用户只是想换章时被强制续读。
- 漫画库切换后，记录仍在应用本机数据库中；打开时优先用当前库的同 UUID 漫画资料。

## 16. 设置：外观

### 16.1 主题颜色

可选：

- 白色；
- 米白色；
- 浅灰色；
- 深灰色。

每种颜色分别定义浅色和深色环境下的背景。卡片、输入框、导航栏颜色从背景混合计算，
保证页面风格一致，而不是只修改某一个页面。

### 16.2 深色模式

- 跟随系统；
- 始终浅色；
- 始终深色。

主题颜色和明暗模式独立组合并保存到本机数据库。

## 17. 设置：漫画库位置

### 17.1 保存位置

点击“保存位置”前会先全局暂停下载。选择器允许选：

- 漫画库根目录；
- 根目录的父目录；
- 包含“漫画”子目录的目录；
- 下一层任意包含 `拷贝漫画总索引.db` 的目录。

系统选择器取消时保持当前库不变。

### 17.2 外置库工作索引

外置盘中的总索引不直接打开写入。首次选择时：

1. 验证外置根目录中存在总索引。
2. 用外置路径、数据库长度、头尾各 4096 字节计算稳定库 ID。
3. 在应用支持目录建立 `external_libraries/<ID>/`。
4. 流式复制总索引到 `.partial`，每约 5% 更新进度。
5. 完成后原子改名。
6. 外置库存在 WAL 时一并复制。
7. SQLite 只打开本机工作副本。
8. ZIP 和封面仍从外置根目录读取。

以后选择同一份库时复用已有工作索引，不覆盖本机其他漫画库的工作索引。

### 17.3 恢复默认位置

该按钮只在当前使用外置库时启用。执行顺序：

1. 全局暂停下载；
2. 关闭当前 SQLite；
3. 释放 Android 持久目录授权或 iOS security scope；
4. 删除保存的外置位置标志；
5. 打开应用默认“漫画”目录；
6. 重新加载收藏缓存和下载任务。

界面提示“现在可以拔盘”后再物理拔出。iPadOS 没有通用的推出按钮，本功能负责关闭本应用
持有的资源，但仍应确认没有其他应用正在写盘。

### 17.4 补建本地索引

用于只有漫画文件夹和 ZIP、索引缺记录的情况：

- 只扫描漫画库第一层非隐藏目录；
- 目录内有 ZIP 或图片才视为漫画；
- 文件夹最后一个“` - `”前为漫画名，后为作者；
- 无作者分隔符时作者为“未知作者”；
- 纯本地 UUID 根据文件夹名稳定生成并以 `local-` 开头；
- 图片作为封面；
- ZIP 作为“本地章节”组；
- 只 `INSERT OR IGNORE`，不覆盖已有在线匹配记录；
- 新记录从当前最大 `library_order + 1` 追加到底部；
- 最后重建简繁搜索索引。

## 18. 设置：内容线路和 API 节点

### 18.1 接口线路

- 海外线路：默认从海外发现入口取节点。
- 国内线路：从国内发现入口取节点。
- 自动选择：合并国内和海外候选，由测速和实际发现结果判断 `region`、
  `in_mainland`。

切换线路时清空旧动态节点、回到该线路主入口、设为自动节点模式、重新发现并测速。

### 18.2 当前 API 节点

可以：

- 自动使用最低延迟可用节点；
- 手动锁定动态节点；
- 输入自定义域名。

输入值会去掉 `http://`、`https://`、路径和末尾斜杠，再转小写。已退休域名会迁移到
当前默认域名。自定义域名为空时拒绝保存。

### 18.3 上游动态节点

刷新时请求原版的 `network2` 接口：

- 成功后递归提取响应中的合法域名；
- 排除已退休节点；
- 并发匿名测速；
- 不发送账号 Token；
- 自动模式选择最低延迟可用节点；
- 发现失败时保留当前节点，不把节点列表清空。

成功发现缓存 30 分钟；完全失败 2 分钟后才重试，防止每个请求都重复打发现接口。

### 18.4 账号 API 节点

账号节点与内容节点独立：

- 只从国内入口发现；
- 可以自动选最低延迟国内节点；
- 可以手动锁定；
- 可以输入自定义账号节点；
- 测速使用匿名搜索探针，不携带账号、密码或 Token；
- 登录和所有 `authenticated` 请求才使用此节点池。

这解决了海外内容节点能看漫画、但账号数据库不互通而提示账号不存在的问题。

## 19. 设置：并发

### 19.1 批量详情扫描

- 范围 1–10；
- 默认 4；
- 控制同时更新多少部漫画详情；
- 不控制单部漫画的章节分页顺序。

### 19.2 漫画图片下载

- 范围 1–10；
- 默认 4；
- 控制同一章节同时下载多少张图片；
- 章节任务本身仍按队列逐章处理。

并发值立即保存。高并发会增加服务器请求、内存、SSD 临时写入和被限流的概率，出现大量
超时应降低并发，而不是反复点击重试。

## 20. 漫画库文件命名

```text
漫画/
├── 拷贝漫画总索引.db
└── 漫画名 - 作者/
    ├── 漫画名 - 作者 - 汇总.jpg
    ├── 漫画名 - 作者 - 第001话.zip
    └── 漫画名 - 作者 - 单行本01.zip
```

- 每部漫画一个目录。
- 每章、每卷或每本一个 ZIP。
- 应用保留上游章节名，不自行把卷改成话。
- 跨平台非法字符会被文件名工具过滤。
- 共享索引只保存相对路径，移动整个“漫画”目录后仍可使用。

## 21. 数据写入边界

| 数据 | 写入位置 |
| --- | --- |
| 漫画 UUID、名称、作者、目录、来源、顺序 | 共享 `拷贝漫画总索引.db` |
| 章节 UUID、分组、标题、顺序、ZIP 相对路径 | 共享 `拷贝漫画总索引.db` |
| 正式下载的章节 ZIP、汇总封面 | 漫画库目录 |
| 简介、状态、地区、主题、热度 | 本机 `copy_manga_reader_local.db` |
| 收藏缓存 | 本机数据库，按漫画库隔离 |
| 下载任务与进度 | 本机数据库，按漫画库隔离 |
| 最近观看、阅读进度 | 本机数据库 |
| 简繁搜索索引 | 本机数据库，按漫画库隔离 |
| 主题、筛选、排序、并发、节点设置 | 本机数据库 |
| 登录 Token 和选中目录授权 | 系统安全存储/平台持久授权 |
| 在线阅读图片 | 系统临时缓存 |

## 22. 明确不支持或不会自动执行的行为

- 不把整个远端目录镜像成 JSON。
- 不把应用界面状态塞进漫画库总索引。
- 不直接修改外置盘总索引工作副本的源文件。
- 不在在线阅读时自动生成 ZIP。
- 不在点击未下载章节时直接入队。
- 不自动把纯本地漫画猜测匹配到远端。
- 不删除漫画文件来清理任务。
- 不保证服务器线路永久有效；协议变化需按逆向维护手册更新。
