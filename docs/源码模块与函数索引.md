# 源码模块与函数索引

本文把当前项目的功能落实到源码文件、类和关键函数。修改功能前先查本表，可以避免把
协议逻辑写进页面、把本机状态写进共享索引，或只修一个入口而漏掉批量流程。

以下“写入”列中的“共享库”指 `拷贝漫画总索引.db`，“本机库”指
`copy_manga_reader_local.db`。

## 1. 启动和依赖组装

### `lib/main.dart`

| 类/函数 | 输入与触发 | 行为 | 写入/副作用 |
| --- | --- | --- | --- |
| `main()` | 进程启动 | 初始化 Flutter binding，挂载启动组件 | 无 |
| `CopyMangaReaderBootstrap.initState()` | 根组件创建 | 构造网络、数据库、控制器并异步初始化 | 无 |
| `_initialize()` | 启动一次 | 按设备身份→本机库→外观→历史→OpenCC→漫画库→节点→会话→收藏/下载顺序恢复 | 打开数据库、读取安全存储 |
| `dispose()` | 应用根组件销毁 | 关闭两个数据库并释放控制器 | WAL checkpoint、连接关闭 |
| `CopyMangaReaderApp.build()` | 主题状态变化 | 构建 MaterialApp 和明暗主题 | 无 |
| `_theme()` | 主题颜色、亮度 | 生成统一的 Material 3 色板、卡片、输入框和导航样式 | 无 |

依赖关系：

```text
CopyClient
├── CopyApiTransport
└── ChineseSearchNormalizer

LibraryDatabase
├── LocalAppDatabase
└── ChineseSearchNormalizer

LibraryController ── LibraryDatabase + LibraryLocator + CopyClient
DownloadController ─ LibraryDatabase + CopyClient
FavoritesController ─ LibraryDatabase + CopyClient
SessionController ─── CopyClient + FlutterSecureStorage
ReaderController ──── ReadingHistoryController + ZipBook/OnlineChapterBook
```

| `_requireLogin()` | 会员接口调用前拒绝空 Token |
| `_networkErrorMessage()` | 统一 Dio 网络错误文字 |

错误分类很重要：

- 404/405/410、网络失败、无效 JSON、空结果：节点故障，可切下一个候选。
- 服务端业务 `code != 200`：业务错误，直接展示，不应用其他节点掩盖“密码错误”等结果。
- 已认证请求 HTTP 401：登录过期。

## 9. 数据模型

### `Comic`

- `stableIdentity`：UUID → path_word → 标题作者。
- `fromDatabase()`：读取 JOIN 后的完整本地视图。
- `fromApi()`：兼容嵌套 comic、作者列表、状态对象和末章对象。
- `copyWith()`：远端详情与本地目录/来源/顺序合并。

### `Chapter`

- `isDownloaded` 只看 `archiveRelativePath` 是否非空。
- `fromApi()` 兼容数值或字符串 `ordered`。
- 分组名由详情返回的章节组决定。

### `DownloadTask`

- 五态：queued/downloading/paused/completed/failed。
- `copyWith()` 只允许改变状态、进度和错误，任务身份保持不变。
- 数据库未知状态回退 queued。

### `ComicSourceFilter` / `ComicSortMode`

- 来源筛选严格对应 `source_kind`。
- 原始排序和首字母排序只在内存修改显示序列。

## 11. 维护工具

### `tool/append_missing_local_comics.py`

扫描已有文件夹，把总索引没有的纯本地漫画和章节追加到末尾。操作前应备份数据库，不能
把它当成日常打开漫画库的必需步骤。

### `tool/migrate_library_metadata.py`

迁移旧索引中的来源、顺序和排序键等元数据。正式运行前先对副本验证行数和筛选结果。

### `tool/convert_library_to_jxl.py`

批量无损转换 ZIP 内可转换图片为 JPEG XL，支持临时文件、断点、统计和源目标目录控制。

### `tool/package_macos.sh`

构建 macOS Release，修复 native-asset 增量构建可能留下的内外层签名不一致，执行
严格签名校验，再生成带版本号的 ZIP、DMG 和 SHA-256 校验和。设置
`MACOS_SIGN_IDENTITY` 时切换到 Developer ID 与 Hardened Runtime。
它属于离线库维护工具，不参与手机应用运行。

### JXL 暂停/继续脚本

- `暂停JXL整库转换.command`：停止 launchd 转换任务，供拔盘。
- `继续JXL整库转换.command`：读取本机忽略的 plist 配置并继续任务。
- `.plist.example` 只包含占位符；真实路径 plist 被 Git 忽略。
