# 使用手册

本文以 0.4.0 版本为准，说明 Android、iPhone、iPad 和 Mac 上的漫画库导入、
在线阅读、正式下载、批量补缺、外置盘使用和备份方法。

需要核对每个按钮的启用条件、数据写入位置、暂停/恢复细节和异常行为时，参阅
[完整功能与交互行为](完整功能与交互行为.md)。

## 1. 第一次启动

应用启动后会依次完成：

1. 打开本机状态数据库 `copy_manga_reader_local.db`。
2. 恢复主题、筛选、排序、接口线路和安全存储中的登录令牌。
3. 查找上次使用的漫画库；第一次启动则创建默认 `漫画` 目录。
4. 打开或创建 `拷贝漫画总索引.db`。
5. 为本地漫画名和作者建立简繁搜索索引。
6. 恢复收藏缓存、下载任务和最近观看。

大漫画库第一次建立搜索索引时可能需要等待。此过程不解压全部章节 ZIP。

## 2. 导入漫画库

### 2.1 Android 默认目录

将电脑上的整个 `漫画` 目录内容复制到：

```text
/storage/emulated/0/Android/data/com.othbradar.copymangareader/files/漫画
```

推荐复制整个目录而不是只复制数据库。至少应同时包含：

- `拷贝漫画总索引.db`
- 每部漫画的文件夹
- 各章节 ZIP
- 汇总封面

ADB 示例：

```bash
adb devices
adb push "/电脑上的路径/漫画/." \
  "/storage/emulated/0/Android/data/com.othbradar.copymangareader/files/漫画/"
```

复制过程中不要让应用同时下载漫画。复制完成后在漫画库菜单中点“刷新本地索引”，
或重启应用。

### 2.2 iPhone / iPad 默认目录

通过 Finder、“文件”App、AirDrop 或其他文件工具，把漫画库放到：

```text
我的 iPhone / iPad/拷贝漫画阅读器/漫画
```

如果先复制了部分文件，可继续向同一目录补充。不要用空数据库覆盖已经使用中的
总索引。

### 2.3 macOS 默认目录

Mac 首次启动会在应用沙盒的 Documents 目录建立：

```text
~/Library/Containers/com.othbradar.copymangareader.macos/Data/Documents/漫画
```

可以把移动端使用的整个 `漫画` 文件夹内容复制到这里。漫画索引、文件夹、ZIP 和
封面格式完全相同，不需要转换。更方便的方式是在设置里直接选择用户目录或外置盘上
现有的漫画库。Mac 宽窗口自动使用左侧导航栏，窄窗口仍使用和手机一致的底部导航。

### 2.4 直接使用外置盘

1. 把完整 `漫画` 目录放在外置盘。
2. 打开“我的 → 设置与说明 → 保存位置”。
3. 在系统目录选择器中选中包含 `拷贝漫画总索引.db` 的目录。
4. 等待“正在把外置索引复制到本机”的进度结束。

可以选择 `漫画` 目录、它的父目录，或只包含一层 `漫画` 子目录的目录。应用会
自动在当前层和下一层查找总索引。

外置盘模式下：

- 漫画封面和章节 ZIP 仍直接从外置盘读取。
- 外置盘原始 `拷贝漫画总索引.db` 不直接写入。
- 应用对章节和下载状态的更新写入本机工作索引。
- 正式下载的漫画文件会保存到当前选择的外置漫画目录。

拔盘前进入设置点“恢复默认位置”。这个操作会关闭当前漫画库并释放 iOS/macOS
安全书签或 Android 目录授权；操作完成后再在系统中推出磁盘。iPadOS 没有传统
“推出磁盘”按钮时，完成上述关闭流程后再直接拔盘。

## 3. 漫画库页面

漫画库一级页面直接显示本地漫画封面、名称和作者。

顶部操作：

- 搜索框：搜索本地漫画名或作者，支持简体与繁体互查。
- 筛选与排序：按漫画来源筛选，或选择原始顺序、标题首字母顺序。
- 下载任务：打开独立下载页面，角标显示等待或正在下载的任务数。
- 漫画库操作：进入“拷贝漫画补缺”或刷新本地索引。

来源筛选：

- 拷贝漫画：只显示拷贝漫画来源。
- 动漫之家：只显示动漫之家独有项目。
- 两边都有：显示已经确认两边对应的项目。
- 全部：不限制来源。

排序只影响显示，不改漫画文件夹、ZIP 名称或总索引中的原始顺序字段。

## 4. 漫画详情与章节

详情页显示封面、名称、作者、状态、简介、本地章节数量和所有章节分组。

章节点击行为分为两类：

- 已下载章节：立即读取本地 ZIP。
- 未下载章节：匿名获取图片列表并在线阅读，页面图片按需进入应用缓存。

在线阅读不会：

- 生成章节 ZIP。
- 把章节标为已下载。
- 加入下载任务。
- 携带会员令牌。

章节前的云图标表示在线章节。详情页顶部“下载全部缺章”和分组右侧下载按钮只负责
打开章节下载选择页，不会在未确认时直接创建任务。

## 5. 正式下载章节

在章节下载选择页可以：

- 勾选单个章节。
- 按章节分组查看缺章。
- 点“全选缺章”。
- 点“取消全选”。
- 确认后把所选章节加入下载任务。

只有这个页面的“加入下载”会创建正式下载任务。下载成功后：

1. 图片临时写入漫画库的 `.download_tmp/<chapter_uuid>`。
2. 所有图片完成后原子生成章节 ZIP。
3. ZIP 使用“漫画名 - 作者 - 章节名.zip”命名。
4. 总索引或外置库的本机工作索引记录 ZIP 相对路径。
5. 临时页文件被清理。

## 6. 下载任务

下载页面支持：

- 全局暂停与全部继续。
- 实时显示整章进度。
- 失败任务单独重试。
- 清空全部任务记录。

“清空下载任务”只删除任务记录，不删除已经完成的漫画 ZIP。

应用退出时正在下载的任务会在下次启动时显示为安全暂停，避免把中断任务错误标为
完成。临时页面可供后续重新下载时复用。

图片下载并发数在“设置与说明 → 并发设置”中调整，范围为 1–10。网络不稳定、
设备发热或服务器限速时应降低并发。

## 7. 批量检查更新和缺章

进入“漫画库 → 右上角菜单 → 拷贝漫画补缺”：

1. 点“开始扫描”检查所有具有拷贝漫画标识的项目。
2. 应用并发获取详情、简介、章节分组和章节列表。
3. 已有 ZIP 的章节不会重复加入缺章。
4. 动漫之家独有且没有拷贝漫画标识的项目会跳过。
5. 单项失败最多自动尝试三次。
6. 扫描结束可点“重试全部失败项”。
7. 确认结果后点“全部缺章加入下载”。

点“重新扫描”会忽略上次结果重新检查，适合隔一段时间后查找新连载章节。

批量扫描并发数也在“并发设置”中调整，范围为 1–10，并且与图片下载并发相互
独立。

## 8. 搜索、登录和收藏

### 在线搜索

“搜索”页查询拷贝漫画服务。搜索结果点开前会核对返回的 `path_word` 和真实漫画
UUID，防止进入错误详情。

### 登录

账号密码只用于当次登录请求。应用保存登录成功后返回的令牌，不保存密码。令牌存储
在 Android Keystore 或 Apple Keychain 支持的安全存储中。

“我的 → 切换账号”可以添加多个账号。点已保存账号即可切换，不需要再次输入密码，
也不会为了切换重新发送登录请求。每个账号分别保存登录令牌、昵称和账号 API 节点；
登录令牌过期时在该账号的菜单中选择“重新登录”。添加新账号失败时仍保留原账号。

升级时会保留原账号，复制旧漫画收藏缓存到原账号的分账号缓存中，旧表不删除。
漫画和小说收藏按账号分别显示；切换、退出或移除本机账号都不删除收藏缓存、
服务器收藏、本地漫画/小说、下载任务或阅读记录。重新登录同一账号可继续读取其缓存。
“移除本机账号”只删除本机登录凭据和账号列表项，不会注销服务器账号。

账号切换与收藏迁移不同：切换本身不会把 A 的收藏自动添加到 B，也不会取消任何收藏。
切换后点各自收藏页的“同步收藏”读取服务器最新列表；离线显示上次同步缓存。

国内和海外服务的账号数据可能不同。若一个线路提示账号不存在，可在设置中切换账号
API 节点。

### 收藏

登录后点“同步收藏”取得收藏列表。收藏缓存写入本机 SQLite，因此暂时断网时仍可
显示最近一次同步结果。收藏同步属于会员请求，会携带令牌。

## 9. 阅读器

默认阅读方式是上下连续滚动，页面之间没有人为黑边或间距。

操作：

- 单击：显示或隐藏顶部、底部操作栏。
- 双指缩放：以手指中心缩放。
- 双击：放大；再次双击恢复原比例。
- 工具栏 `+/-`：逐级放大或缩小。
- 放大后单指拖动：可同时水平和垂直移动。
- 阅读方向按钮：切换上下连续或左右单页。

在线章节只预取当前页附近图片；已经缓存的页面再次进入时直接复用。缓存由系统管理，
空间不足时可能被清理。需要永久保存的章节必须走正式下载。

阅读位置按章节 UUID 保存。最近观看按漫画记录最后打开的章节、页码和时间。

## 10. 主题与界面

“设置与说明 → 外观”中可以选择：

- 白色
- 米白色
- 浅灰色
- 深灰色

深色模式可以选择：

- 跟随系统
- 始终浅色
- 始终深色

主题和深色模式只写当前设备的独立数据库，不会写入共享漫画索引；需要迁移时可通过
下一节导出可携式应用数据。

## 11. 备份和迁移

完整内容备份至少包含整个 `漫画` 目录。它保存漫画索引、封面和所有章节 ZIP。

跨平台迁移应用数据时，不要直接替换各系统私有目录里的
`copy_manga_reader_local.db`。应用提供了带格式标识和库路径重映射的 SQLite
快照：

1. 在源设备打开要搬运的漫画库。
2. 进入“我的 → 设置与说明 → 应用数据迁移”。
3. 点“导出到当前漫画库”。应用会先安全暂停下载，然后在漫画库根目录原子生成
   `拷贝漫画阅读器应用数据.db`。
4. 把整个漫画库复制到 Android、iPhone、iPad 或 Mac。
5. 新设备先选择并成功打开该漫画库，再点“从当前漫画库导入”。
6. 应用把 `library_key` 重映射到新设备当前工作索引，并立即重载主题、最近观看、
   筛选、收藏缓存和下载任务。

导入采用合并方式；主键相同的记录以备份为准。原来处于等待或下载中的任务会转成
暂停，用户确认后再继续。可携式数据库包含：

- 最近观看和章节阅读位置；
- 主题、深色模式、筛选、排序、并发与 API 节点设置；
- 当前漫画库的详情、简介、收藏和简繁搜索缓存；
- 当前漫画库的下载任务。

它不包含账号密码、登录令牌、系统目录权限或任何签名材料。共享
`拷贝漫画总索引.db` 的表和字段不会被此次导入、导出修改。

推荐顺序：

1. 全局暂停下载。
2. 等待当前文件写入停止。
3. 需要迁移阅读记录等状态时先导出应用数据。
4. 外置盘模式下点“恢复默认位置”。
5. 复制整个漫画目录。
6. 比对文件数量、总大小或校验和。
7. 在新设备选择该漫画库并等待索引完成，然后按需导入应用数据。

不要在两个设备同时向同一个可写外置漫画库下载同一章节。
