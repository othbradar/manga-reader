# 故障排查

## 漫画库打开失败

### 提示缺少必要表

所选 SQLite 不是本项目的总索引，或文件复制不完整。确认目录中是
`拷贝漫画总索引.db`，并检查 `comics`、`chapter_groups`、`chapters` 和
`download_queue` 表。

不要用空数据库覆盖原文件。

### 提示 unable to open database file

常见原因：

- 外置盘已拔出或目录授权失效。
- 目录不可写。
- 数据库复制尚未完成。
- SQLite 的 `-wal` 文件与主库不一致。

重新连接外置盘，在设置中重新选择漫画目录。拔盘前先“恢复默认位置”。

### 能打开但找不到刚替换的外置索引

外置库使用本机工作索引，同一个外置库再次打开会复用已有工作副本。若需要用全新
外置索引重新初始化，可先备份本机阅读进度，清除应用数据或卸载重装，再重新选择
外置库。不要直接删除外置原始索引。

## 漫画列表为空

1. 检查总索引中 `comics` 是否有记录。
2. 把来源筛选改成“全部”。
3. 清空搜索框。
4. 点“刷新本地索引”。
5. 如果数据库为空，使用“补建本地索引”扫描漫画文件夹和 ZIP。

补建只添加缺失记录，不应删除原漫画文件。

## 简体搜不到繁体漫画

确认 `assets/opencc/STCharacters.txt` 和 `TSCharacters.txt` 已打入应用。然后：

1. 清空旧查询。
2. 重启应用等待本机搜索索引刷新。
3. 同时尝试漫画名和作者名。

不要修改原漫画标题来解决搜索问题。

## 封面不显示

应用优先读取 `cover_relative_path`。检查：

- 文件是否仍位于漫画库根目录之下。
- 文件名和数据库相对路径大小写是否完全一致。
- 外置盘是否区分大小写。
- 图片是否是可解码的 JPEG、PNG 或 WebP。

在线详情可重新缓存缺失封面，但不会替换已经存在的正常封面。

## 点未下载章节打不开

在线阅读需要：

- 漫画有有效 `path_word`。
- 章节有有效 UUID。
- 内容 API 节点可用。
- 图片 CDN 可访问。

动漫之家独有且没有拷贝漫画对应关系的章节不能在线读取，只能读取本地 ZIP。

单页失败时点阅读器中的“重试”。如果整个章节图片列表失败，在设置中刷新动态节点
或切换国内/海外线路。

## 点章节却开始下载

0.3.16 以后未下载章节点击应直接在线阅读。真正下载只能在详情页的下载按钮进入
“选择下载章节”二级页后确认。

如果仍直接下载，检查安装版本：

```bash
adb shell dumpsys package com.othbradar.copymangareader |
  grep -E 'versionCode|versionName'
```

应至少为 `versionName=0.3.16`、`versionCode=24`。

## 下载没有进度

1. 打开“漫画库 → 下载任务”。
2. 确认没有处于全局暂停。
3. 检查任务是否为等待中、下载中或失败。
4. 降低图片下载并发数。
5. 失败任务点单独重试。

清空任务不会删除已完成 ZIP。需要重下某个已完成章节时，应先确认索引和 ZIP 的实际
状态，不要直接批量删除漫画目录。

## 下载后仍显示缺章

检查：

- 最终 ZIP 是否存在。
- 是否只留下 `.partial` ZIP。
- SQLite `archive_relative_path` 是否为漫画库相对路径。
- 当前页面是否还在使用旧列表，返回漫画库后刷新。
- 外置库模式下是否打开的是同一个本机工作索引。

## 阅读器跳回旧位置

阅读进度在滚动停止后写入本机数据库。若应用被强制结束，最后极短的一段移动可能尚未
写入。

如果反复跳到底部：

- 确认安装 0.3.2 以上版本。
- 检查章节 UUID 是否被多个不同章节错误共用。
- 备份后检查本机 `read_progress` 表。

不要修改共享漫画索引来清理阅读位置。

若慢速上下滑动时突然回到顶部，先确认版本不低于 0.4.3+28。旧版图片被内存缓存
回收后，重新解码期间高度会暂时归零，引发 Sliver 滚动位置校正；这不是阅读进度
写入失败，删除阅读记录或漫画索引不能修复。新版保留页面尺寸并修正恢复锚点前的
页面顺序。若仍出现，请记录章节、页码、是否放大、在线/本地和设备型号。

## 缩放后不能自由移动或跨页

确认安装 0.3.5 以上版本。连续模式放大后，单指应可斜向移动；垂直位移到达当前
视口边界后应继续滚动前后页。

若只在某一章出现，检查图片尺寸是否异常或是否有损坏页。

## 登录提示账号不存在

账号线路可能不互通：

1. 用原版应用确认账号密码。
2. 设置接口线路为国内。
3. 进入“账号 API 节点”刷新并选择可用国内节点。
4. 不要反复高频尝试，以免触发账号风控。

搜索和在线阅读正常不代表账号节点正常，因为匿名内容与会员账号是不同请求。

## 所有内容 API 节点失败

1. 在设置中刷新上游动态节点。
2. 改为自动选择，查看当前节点和延迟。
3. 国内直连失败时尝试海外线路；海外线路慢时尝试国内线路。
4. 检查系统 VPN 或代理是否只对部分域名生效。
5. 单独判断搜索、详情、章节和图片 CDN 哪一层失败。

应用不会自动读取电脑的 `127.0.0.1` 代理；手机上的回环地址指向手机本身。

## 外置盘准备拔出

1. 全局暂停下载。
2. 退出阅读器。
3. 设置中点“恢复默认位置”。
4. 等待成功提示。
5. 再拔出外置盘。

iPadOS 没有推出按钮时仍应先完成上述关闭流程。

## 收集 Android 日志

```bash
adb logcat -c
adb shell am start -W \
  -n com.othbradar.copymangareader/.MainActivity
adb logcat -d -t 500 > reader-log.txt
```

分享日志前删除账号、令牌、私人路径等敏感信息。

## 发布包无法安装

### Android

- 检查 APK 是否完整。
- 检查签名是否与已安装版本一致。
- Bundle ID 应为 `com.othbradar.copymangareader`。

### iOS/iPadOS

- 仓库生成的是未签名 IPA，必须先签名。
- 标准 ID 和 iPad 兼容 ID 不能互相覆盖。
- 签名工具使用的 Bundle ID 必须与目标已安装应用一致。
- 兼容包 ID 为 `app.plantain7005.quartz6563`。
