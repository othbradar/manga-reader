# 拷贝漫画接口维护

拷贝漫画服务会更换域名、线路、版本参数、请求头和接口返回结构。本项目把这些变化
集中在服务层，避免每次变更都重写页面。

拿到新版原版 APK 后，不要直接凭字符串修改协议。完整取证、Flutter AOT 分析、
动态请求验证和版本差分流程见[原版 APK 逆向与协议迁移](原版APK逆向与协议迁移.md)。
2026-10-27 的完整增量证据、排除路径、小说接口及收藏验收见
[最新协议复核记录](2026-10-27_协议复核与收藏验收.md)。

## 1. 文件职责

| 文件 | 只负责 |
| --- | --- |
| `lib/services/copy_api_protocol.dart` | 路径、方法白名单、业务参数、节点配置和公共协议门面 |
| `lib/services/copy_request_protocol.dart` | 3.0.9 普通 API 共用签名、启动参数与 POST 表单 |
| `lib/services/copy_api_transport.dart` | HTTP、节点发现、测速、故障切换和令牌 |
| `lib/services/copy_client.dart` | 业务请求和响应到 Model 的转换 |
| `lib/services/copy_novel_client.dart` | 小说搜索、详情、分卷、内容与收藏，复用同一传输层 |
| `lib/services/copy_device_identity.dart` | 平台设备身份 |
| `lib/controllers/session_controller.dart` | 登录令牌安全存储和会话 |
| `test/copy_api_protocol_test.dart`、`test/request_profile_matrix_test.dart` | 协议、最终请求矩阵与鉴权边界 |
| `test/account_request_safety_test.dart` | 表单实际字节、串行通道、首错停止和禁止账号重放 |

页面和 Controller 不应出现：

- API 域名。
- `/api/v3/...` 路径。
- 版本号或平台参数。
- HMAC、Authorization 或设备请求头。
- 针对原始 JSON 字段的散乱解析。

## 2. 先判断故障层级

服务异常时按顺序判断：

1. 图片 CDN 是否可访问。
2. 内容 API 节点是否可访问。
3. 动态节点发现接口是否返回新节点。
4. 搜索接口是否返回正确 `path_word`。
5. 详情接口返回的 `path_word` 和 UUID 是否匹配请求。
6. 章节分组是否有数量但列表为空。
7. 章节内容接口是否返回图片列表。
8. 登录接口和资料验证接口是否属于同一账号线路。
9. 只有会员接口失败，还是匿名接口也失败。

不要因为登录失败就给所有匿名请求带令牌。这样会扩大账号风控影响。

## 3. 更新节点

静态入口和动态发现配置位于 `CopyApiProtocol`：

- `defaultDomain`
- `discoveryDomains`
- `overseasDomains`
- `mainlandDomains`
- `retiredDomains`
- `networkPath`

新增节点时：

1. 先确认它是内容节点、账号节点还是两者都支持。
2. 确认国内/海外属性，以便设置 `region` 和 `in_mainland`。
3. 放入正确线路，不要直接替换全部后备。
4. 旧节点失效时放进 `retiredDomains`，让用户保存的旧设置迁移到当前默认节点。
5. 补充节点发现、测速和故障切换测试。

动态节点有成功缓存和失败重试间隔。测试时需要显式调用刷新，不能只重启页面。

## 4. 更新请求头或签名

从 0.5.0+32 起，所有普通 API 共用 `CopyRequestProtocol`：登录、资料、收藏、漫画和小说
搜索/详情/章节、节点发现/测速均使用同一套初始化后参数与证书派生签名。
不再保留匿名旧签名、初始 FlutterTest 参数或登录专用旧头。图片/TXT CDN 独立请求。

修改时记录：

- 官方客户端版本。
- API 版本。
- versionCode。
- platform。
- region。
- User-Agent。
- 签名时间单位。
- HMAC key、message 和编码方式。
- 空 Authorization 是否有协议意义。

签名必须使用固定时间测试向量，不能只测试“返回非空字符串”。

## 5. 更新登录

登录流程：

1. 用户名和密码由 `loginBody` 编码。
2. 合并公共表单参数，向选定的国内账号节点提交一次；不自动跨节点重放凭据。
3. 返回 token 后先只放入内存。
4. 立即调用会员资料接口验证。
5. 验证成功才交给 `SessionController` 写安全存储。
6. 验证失败清空内存 token。

如果服务提示“账号不存在”：

- 先用原版应用验证账号。
- 切换国内账号节点。
- 检查登录请求是否仍为表单编码。
- 检查密码 salt 与 Base64 格式。
- 检查公共 version/platform 及当前账号节点的 region；不要重新分叉出登录专用旧签名。
- 不要把内容节点测速结果直接当成账号节点结果。

账号密码不得写入日志、数据库或测试夹具。测试使用模拟 Dio Adapter。

## 6. 更新搜索和详情

搜索结果不能直接当成最终漫画记录。打开详情前必须：

1. 保留搜索结果的 `path_word`。
2. 请求该 `path_word` 的详情。
3. 校验返回 `path_word` 与请求一致。
4. 使用详情返回的真实 UUID。
5. 再写入漫画索引或本机详情缓存。

这样可避免搜索结果 UUID 缺失、占位或对应错误漫画。

简繁转换在 `ChineseSearchNormalizer`，不应通过修改 API 查询字段解决。

## 7. 更新章节接口

章节目录和章节图片是两步：

1. `comicDetails` 返回分组。
2. `groupChapters` 分页返回章节。
3. `chapterContent` 返回某章图片 URL。

如果分组声明还有章节但当前页返回空列表，应判为节点失败并切换节点。

章节内容当前有多个兼容候选。维护时：

- 把原版客户端当前使用的接口排在第一。
- 保留仍可用的兼容接口。
- 每个候选都验证图片列表非空。
- 匿名成功时不要设置 `authenticated: true`。
- 图片 Content-Type 不可靠，应按返回字节处理。

在线阅读和正式下载共用章节 URL 获取，但后续存储不同：

- 在线：写系统缓存，不生成 ZIP。
- 下载：写 `.download_tmp`，全部完成后生成 ZIP 和索引记录。

## 8. 错误与节点切换

可以触发候选节点切换的传输错误：

- 连接、超时、DNS 等 Dio 网络错误。
- HTTP 404、405、410。
- 非 JSON 或空响应。
- 业务结果结构不符合当前请求的 validator。

明确的业务错误，例如密码错误，不应在所有节点无限重试并掩盖真实消息。

401 会员错误只在明确过期、非风控情况下交给会话层续期：保存过密码时单次重新登录，
用候选 Token 验证 profile 身份，安全存储成功后原子替换当前凭证。缺少密码或失败时
保留原账号与收藏并提示重新登录，不清空账号。详见“2026-10-28 会话与收藏增量”。

## 9. 必须保留的测试

接口变更至少运行：

```bash
flutter test --no-pub test/copy_api_protocol_test.dart
```

并确保下列行为仍被覆盖：

- 固定签名向量。
- 匿名 API 使用原版未登录的空 `Token `，CDN 完全没有 Authorization；都不能携带会员 Token。
- 登录请求不携带旧会员令牌。
- 登录 token 经资料接口验证。
- 会员接口才携带 token。
- 空章节列表触发节点切换。
- 章节兼容接口按顺序回退。
- 国内/海外节点同步改变 region 和 `in_mainland`。
- 动态节点选择最低延迟节点。
- 搜索 `path_word` 对应真实详情 UUID。

最后再运行：

```bash
dart analyze --fatal-infos
flutter test --no-pub --concurrency=1
```

不要只凭原版应用“能打开”就发布；必须分别验证搜索、详情、章节列表、章节图片、
登录、资料和收藏。

## 10. 当前 3.0.9 协议基线

这张表是当前代码实际发送的基线，不代表上游永久不变。更新原版 APK 后应逐项核对，而不是
只改一个域名。

### 10.1 所有普通 API 的公共参数（0.5.0+32）

| 项目 | 当前值/规则 |
| --- | --- |
| version / versionCode | `3.0.9` / `83` |
| platform | header/form 字符串 `3`；query 整数 `3` |
| source / webp | `copyApp` / `1` |
| User-Agent / referer | `COPY/3.0.9` / `com.copymanga.app-3.0.9` |
| region | 海外 `1`，国内 `0`；`-0800` 是日期构造时区，不是线路值 |
| dt | 启动时墙钟文本前 19 位拼 `-0800` 后 parse；header 格式 yyyy.MM.dd，进程内不随请求更新 |
| timestamp | 每请求当前 Unix 秒 |
| tapString | 原版 APK 公共证书 MD5，详见逆向文档 §33 |
| signature | HMAC-SHA256，key=UTF8(tapString)，message=UTF8(timestamp)，小写 hex |
| umString | MD5(UTF8(tapString))，小写 hex |
| device（Android） | Build.ID，注意不是 Settings.Secure.ANDROID_ID，也不是型号 |
| deviceInfo（Android） | Build.MODEL + "-" + Build.DEVICE |
| pseudoID | 16 位 base62 随机安装标识；本地应用 SQLite 的 device_identity 表，不随跨设备备份迁移 |
| Accept-Language | 原版普通拦截器默认空字符串 |
| authorization | 未登录/内容请求为空 `Token `；仅白名单会员接口为 `Token <token>` |

Header 完整键：

```text
Accept, Accept-Language, User-Agent, platform, source, version, versionCode,
authorization, webp, region, referer, deviceInfo, pseudoID, umString, device,
dt, X-Auth-Timestamp, X-Auth-Signature
```

`userAgent/androidId/tapString/isGoogle/buildTime` 是 extra/form 字段，不能一股脑复制成
Header。POST 在业务字段后合并公共 extra，再进行 URL-encoded 编码；GET 不发送这些表单字段。
所有 API query 统一补/覆盖 `platform=3`。初始化设备参数失败时禁止 API 发送；本地阅读仍可用。
iOS/macOS 使用阅读器各平台自身元数据，不复制安卓手机或原版安装的私有标识；
这不是原版 iOS 客户端协议也已逐项核验的证明。

### 10.2 登录请求

| 项目 | 当前值/规则 |
| --- | --- |
| path | `/api/v3/login` |
| method | POST |
| Content-Type | `application/x-www-form-urlencoded` |
| User-Agent | `COPY/3.0.9` |
| version | `3.0.9`（启动后覆盖初始的 3.0.0） |
| platform | Header/form 为字符串 `3`；query 为整数 `3` |
| source | `copyApp`（原生渠道，覆盖初始 FlutterTest） |
| webp | `1` |
| region | 国内账号线路 `0` |
| salt | 每请求 `Random.secure().nextInt(9999)`，转字符串 |
| password | `Base64(UTF8("$password-$salt"))` |
| Token | 登录 Header/form 使用空 `Token `，绝不带旧会员 Token |
| tapString | 公共 APK 签名证书的 MD5；不是用户密钥 |
| umString | `MD5(UTF8(tapString))` |
| 签名 | `HMAC-SHA256(UTF8(tapString), UTF8(Unix秒))` |
| POST | 业务字段后合并公共参数，与 Header 由同一份参数生成 |

登录使用独立账号节点池。不要因为内容线路设为海外，就把登录也发到海外内容节点。
所有账号请求共享串行通道，前一次完成后至少间隔 1 秒；相同的在途收藏 GET 合并。
限流遵守 `Retry-After`，明确账号限制立即停止后续账号请求。小说批量收藏首次失败
即停止，也不再自动读回。0.5.1+33 已在用户登录的 Mac 会话中完成单本与批量收藏
回查验收，见最新记录；这不能承诺解除既有账号限制，也不等于已逐个平台抓包验证。

### 10.3 当前入口

| 类型 | 当前基线 |
| --- | --- |
| 默认内容入口 | `api.manga2026.xyz` |
| 国内入口 | `api.copy202602.com` |
| 旧国内后备 | `mapi.mangacopy.com` |

## 11. 当前接口逐项字典

### 11.1 动态节点

```text
GET /api/v3/system/network2
query:
  platform=3
auth:
  anonymous
expected:
  code=200
  results.api 可递归提取域名
  results.in_mainland 可选
```

调用者：

- 内容线路：`_refreshDynamicDomains()`。
- 账号线路：`_refreshAuthenticationDomains()`，只从国内入口请求。

失败语义：

- 发现失败不清除现有节点。
- 内容发现全空时继续使用当前/静态节点。
- 账号发现全空时回退国内静态节点。

### 11.2 节点测速

改为匿名 `GET /api/v3/system/network2?platform=3`，成功条件为 HTTP/code 200 且
results.api 为 List。和节点发现共用同一套 Header，不再用虚构搜索词反复请求搜索接口。
测速超时 5 秒。测得的是完整语义响应时间；自动排序/手动锁定节点属于阅读器功能，
不声称原版的请求调度和探测次数也与阅读器相同。

### 11.3 在线搜索

```text
GET /api/v3/search/comic
query:
  limit=20
  offset=(page-1)*20
  q=<keyword>
  q_type=
  platform=3
auth:
  anonymous
expected:
  results.list
required result fields:
  title/name
  path_word/pathWord
optional:
  uuid, author, cover, alias, brief, status, last_chapter
```

客户端搜索顺序：

1. 原始关键词；
2. 简体变体；
3. 繁体变体；
4. 第一个非空结果立即返回。

### 11.4 漫画详情

```text
GET /api/v3/comic2/<path_word>
query:
  platform=3
  in_mainland=<按实际候选节点重算>
  request_id=
auth:
  anonymous
expected:
  results.comic
  results.groups
semantic validation:
  comic.uuid 非空
  comic.path_word 非空
  comic.path_word == 请求 path_word
```

解析字段：

| 结果 | 模型 |
| --- | --- |
| `comic.uuid` | `Comic.uuid` |
| `path_word/pathWord` | `Comic.pathWord` |
| `name/title` | `Comic.title` |
| `author[].name` | `Comic.authors` |
| `cover` | `Comic.coverUrl` |
| `alias` | `Comic.alias` |
| `brief` | `Comic.brief` |
| `status.display` 或 status | `Comic.status` |
| `last_chapter.name` | `Comic.lastChapter` |
| `groups` | `ComicGroup[]` |

### 11.5 章节列表

```text
GET /api/v3/comic/<comic_path_word>/group/<group_path_word>/chapters
query:
  limit=100
  offset=0,100,200...
auth:
  anonymous
expected:
  results.total
  results.list
```

章节映射：

| 字段 | 模型 |
| --- | --- |
| `uuid` | `Chapter.uuid` |
| `name` | `Chapter.title` |
| `ordered` | `Chapter.order` |
| `size` | `Chapter.pageCount` |
| 当前组 path/name | `groupPathWord/groupName` |

当 `offset < total` 时空 list 是异常；当详情中的组 count 为 0 时不请求。

### 11.6 章节图片与保存 ZIP

按用户 2026-10-27 明确要求，在线阅读与保存 ZIP 共用匿名阅读图片：

```text
GET /api/v3/comic/<path_word>/chapter2/<chapter_uuid>
query: platform=3, in_mainland=<当前节点>, request_id=
auth: 空 Token，不使用已登录会员 Token
expected: results.chapter.contents 中至少一个 URL
```

contents 元素兼容 URL 字符串或 `{"url":"https://..."}`。同一接口空结果可换内容节点，
不再自动尝试旧 `/chapter/` 或账号下载专用 `/chapter2download/`。
后者在这次匿名在线检查中明确返回 401，已经从阅读器调用路径移除。
取得公开阅读图片后仍以每章 ZIP 保存，已有文件名、完成校验和重试策略不变。
账号限制、明确 401/403/429 不当作一般网络失败进行后台反复重试。

### 11.7 图片字节

```text
GET <完整 CDN URL>
responseType=bytes
auth:
  anonymous
headers:
  普通签名/设备头，不带会员 Token
success:
  HTTP 200 且 body 非空
```

调用者包括在线页、正式下载页和封面缓存。落盘前统一按魔数识别扩展名。

### 11.8 会员资料

```text
GET /api/v3/member/info
auth:
  Token <token>
node pool:
  authentication
expected:
  results Map
```

HTTP 401 映射为“登录已过期”。登录流程把此接口作为 Token 有效性的最终验证。

### 11.9 收藏

```text
GET /api/v3/member/collect/comics
query:
  limit=18
  offset=0,18,36...
  free_type=1
  ordering=-datetime_updated
auth:
  Token <token>
node pool:
  authentication
expected:
  results.list
  results.total
```

列表项同时兼容漫画直接位于行内，或位于 `row.comic`。

小说列表使用 `/api/v3/member/collect/books`，同样每页 18 条，行可能包装在 `row.book`。
只有完整分页读取成功才替换缓存；提前空页、重复分页与缺少 list 不能当成空收藏覆盖旧缓存。

### 11.10 收藏写入

| 对象 | 方法和路径 | 业务字段 |
| --- | --- | --- |
| 漫画 | POST `/api/v3/member/collect/comic` | `comic_id=UUID`、`is_collect=1/0` |
| 小说 | POST `/api/v3/member/collect/book` | `book_id=UUID`、`is_collect=1/0` |

必须合并公共 extra 后按 URL-encoded 表单发送；query 补 platform=3；header 和表单
均使用当前账号 Token。单数路径是写入，复数路径是列表，不可混用。
先读状态、相同时不写；写后全量回查 UUID。响应不明确不自动重发，下次用户操作先读状态。
批量只在明确用户操作后执行，跳过已有及 local- 作品，第一笔失败即停止。

### 11.11 小说内容

| 功能 | 方法与路径（均带 `/api/v3` 前缀） | 业务 query / 关键响应 |
| --- | --- | --- |
| 搜索 | GET `/search/books` | q、q_type、limit、offset；list |
| 详情 | GET `/book/{path_word}` | in_mainland、request_id；book.uuid、book.path_word 必须匹配 |
| 卷目录 | GET `/book/{path_word}/volumes` | 无业务分页参数；list、total |
| 卷内容 | GET `/book/{path_word}/volume/{id}` | volume.id、book_path_word、txt_addr、txt_encoding、contents |
| TXT/插图/封面 | GET 响应资源地址 | 独立 CDN 连接，不附 API/账号头 |

全部内容接口按匿名状态发送，统一补 query platform=3；卷目录不是收藏分页接口。
卷目录声明 total 大于实际条数时失败并保留本地目录，不把残缺响应当成全部卷。

## 12. `requestResults()` 的完整决策

```text
收到业务请求
├── authenticated=true 且 Token 为空 → 立即提示登录
├── 登录或会员接口
│   └── 串行账号通道 → 当前账号节点（没有时取动态/国内候选首项）→ 仅尝试这一个节点
└── 匿名内容接口
    └── 准备内容候选：当前节点 → 动态内容节点 → 当前线路静态节点

匿名内容逐候选；账号只执行一轮：
├── 如果 query 有 in_mainland，按当前候选节点重写
├── 发送请求
├── 网络/接口不存在/无效 JSON → 匿名可换节点；账号立即失败，不重放
├── 业务 code != 200 → 直接抛业务错误
├── validator 不通过 → 匿名可换节点；账号立即失败，保留原缓存
└── 成功 → 提升该节点并返回 results
```

因此新增接口时必须回答两个问题：

1. 这是匿名内容还是会员账号接口？
2. 什么数据才算“语义成功”？

没有 validator 的接口容易把风控页、空列表或错误漫画当成功。
账号 POST 也不跟随重定向。明确限制停止当前会话账号通道；429 尊重 Retry-After。
这套约束是阅读器自己的保护策略，不是声称原版采用相同调度。
