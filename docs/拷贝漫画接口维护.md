# 拷贝漫画接口维护

拷贝漫画服务会更换域名、线路、版本参数、请求头和接口返回结构。本项目把这些变化
集中在服务层，避免每次变更都重写页面。

拿到新版原版 APK 后，不要直接凭字符串修改协议。完整取证、Flutter AOT 分析、
动态请求验证和版本差分流程见[原版 APK 逆向与协议迁移](原版APK逆向与协议迁移.md)。

## 1. 文件职责

| 文件 | 只负责 |
| --- | --- |
| `lib/services/copy_api_protocol.dart` | 常量、请求头、签名、路径和参数 |
| `lib/services/copy_api_transport.dart` | HTTP、节点发现、测速、故障切换和令牌 |
| `lib/services/copy_client.dart` | 业务请求和响应到 Model 的转换 |
| `lib/services/copy_device_identity.dart` | 平台设备身份 |
| `lib/controllers/session_controller.dart` | 登录令牌安全存储和会话 |
| `test/copy_api_protocol_test.dart` | 协议与鉴权边界回归 |

页面和 Controller 不应出现：

- API 域名。
- `/api/v3/...` 路径。
- 版本号或平台参数。
- HMAC、Authorization 或设备请求头。
- 针对原始 JSON 字段的散乱解析。

## 2. 先判断故障层级

服务异常时按顺序判断：

1. 图片 CDN 是否可访问。
2. 内容 API 节点是否可访问。
3. 动态节点发现接口是否返回新节点。
4. 搜索接口是否返回正确 `path_word`。
5. 详情接口返回的 `path_word` 和 UUID 是否匹配请求。
6. 章节分组是否有数量但列表为空。
7. 章节内容接口是否返回图片列表。
8. 登录接口和资料验证接口是否属于同一账号线路。
9. 只有会员接口失败，还是匿名接口也失败。

不要因为登录失败就给所有匿名请求带令牌。这样会扩大账号风控影响。

## 3. 更新节点

静态入口和动态发现配置位于 `CopyApiProtocol`：

- `defaultDomain`
- `discoveryDomains`
- `overseasDomains`
- `mainlandDomains`
- `retiredDomains`
- `networkPath`

新增节点时：

1. 先确认它是内容节点、账号节点还是两者都支持。
2. 确认国内/海外属性，以便设置 `region` 和 `in_mainland`。
3. 放入正确线路，不要直接替换全部后备。
4. 旧节点失效时放进 `retiredDomains`，让用户保存的旧设置迁移到当前默认节点。
5. 补充节点发现、测速和故障切换测试。

动态节点有成功缓存和失败重试间隔。测试时需要显式调用刷新，不能只重启页面。

## 4. 更新请求头或签名

普通内容请求由 `CopyApiProtocol.headers` 统一生成。登录请求使用
`loginHeaders`，不要强行合并，因为两套服务的版本协商可能不同。

修改时记录：

- 官方客户端版本。
- API 版本。
- versionCode。
- platform。
- region。
- User-Agent。
- 签名时间单位。
- HMAC key、message 和编码方式。
- 空 Authorization 是否有协议意义。

签名必须使用固定时间测试向量，不能只测试“返回非空字符串”。

## 5. 更新登录

登录流程：

1. 用户名和密码由 `loginBody` 编码。
2. 使用账号候选节点提交表单。
3. 返回 token 后先只放入内存。
4. 立即调用会员资料接口验证。
5. 验证成功才交给 `SessionController` 写安全存储。
6. 验证失败清空内存 token。

如果服务提示“账号不存在”：

- 先用原版应用验证账号。
- 切换国内账号节点。
- 检查登录请求是否仍为表单编码。
- 检查密码 salt 与 Base64 格式。
- 检查登录专用 version/platform/region。
- 不要把内容节点测速结果直接当成账号节点结果。

账号密码不得写入日志、数据库或测试夹具。测试使用模拟 Dio Adapter。

## 6. 更新搜索和详情

搜索结果不能直接当成最终漫画记录。打开详情前必须：

1. 保留搜索结果的 `path_word`。
2. 请求该 `path_word` 的详情。
3. 校验返回 `path_word` 与请求一致。
4. 使用详情返回的真实 UUID。
5. 再写入漫画索引或本机详情缓存。

这样可避免搜索结果 UUID 缺失、占位或对应错误漫画。

简繁转换在 `ChineseSearchNormalizer`，不应通过修改 API 查询字段解决。

## 7. 更新章节接口

章节目录和章节图片是两步：

1. `comicDetails` 返回分组。
2. `groupChapters` 分页返回章节。
3. `chapterContent` 返回某章图片 URL。

如果分组声明还有章节但当前页返回空列表，应判为节点失败并切换节点。

章节内容当前有多个兼容候选。维护时：

- 把原版客户端当前使用的接口排在第一。
- 保留仍可用的兼容接口。
- 每个候选都验证图片列表非空。
- 匿名成功时不要设置 `authenticated: true`。
- 图片 Content-Type 不可靠，应按返回字节处理。

在线阅读和正式下载共用章节 URL 获取，但后续存储不同：

- 在线：写系统缓存，不生成 ZIP。
- 下载：写 `.download_tmp`，全部完成后生成 ZIP 和索引记录。

## 8. 错误与节点切换

可以触发候选节点切换的传输错误：

- 连接、超时、DNS 等 Dio 网络错误。
- HTTP 404、405、410。
- 非 JSON 或空响应。
- 业务结果结构不符合当前请求的 validator。

明确的业务错误，例如密码错误，不应在所有节点无限重试并掩盖真实消息。

401 会员错误应提示登录过期，并由会话层清除失效令牌。

## 9. 必须保留的测试

接口变更至少运行：

```bash
flutter test --no-pub test/copy_api_protocol_test.dart
```

并确保下列行为仍被覆盖：

- 固定签名向量。
- 匿名请求完全省略 Authorization。
- 登录请求不携带旧会员令牌。
- 登录 token 经资料接口验证。
- 会员接口才携带 token。
- 空章节列表触发节点切换。
- 章节兼容接口按顺序回退。
- 国内/海外节点同步改变 region 和 `in_mainland`。
- 动态节点选择最低延迟节点。
- 搜索 `path_word` 对应真实详情 UUID。

最后再运行：

```bash
dart analyze --fatal-infos
flutter test --no-pub --concurrency=1
```

不要只凭原版应用“能打开”就发布；必须分别验证搜索、详情、章节列表、章节图片、
登录、资料和收藏。

## 10. 当前 3.0.9 协议基线

这张表是当前代码实际发送的基线，不代表上游永久不变。更新原版 APK 后应逐项核对，而不是
只改一个域名。

### 10.1 普通内容请求

| 项目 | 当前值/规则 |
| --- | --- |
| appVersion | `3.0.9` |
| apiVersion | `3.0.0` |
| versionCode | `83` |
| platform | `3` |
| source | `#utm_source=FlutterTest` |
| webp | `0` |
| User-Agent | `COPY/3.0.9` |
| referer | `com.copymanga.app-3.0.9` |
| region | 海外 `-0800`，国内 `0` |
| dt | `yyyy.MM.dd` |
| timestamp | 当前 Unix 秒 |
| signature | HMAC-SHA256，时间戳字节同时作为 key 和 message，小写 hex |
| authorization | 匿名完全省略；会员为 `Token <token>` |

普通 Header 的完整键：

```text
Accept
Accept-Language
User-Agent
userAgent
source
platform
version
versionCode
referer
region
webp
umString
device
deviceInfo
androidId
pseudoID
dt
X-Auth-Timestamp
X-Auth-Signature
[authorization]
```

`umString` 来自原版统计 key 的 SHA-256，但不参与 HMAC。设备身份由平台桥接提供，取不到
时使用固定后备值。

### 10.2 登录请求

| 项目 | 当前值/规则 |
| --- | --- |
| path | `/api/v3/login` |
| method | POST |
| Content-Type | `application/x-www-form-urlencoded` |
| User-Agent | `COPY/3.0.0` |
| version | `2025.08.15` |
| platform | `1` |
| webp | `1` |
| region | `1` |
| salt | `1729` |
| password | `Base64(UTF8("$password-$salt"))` |
| Token | 登录请求不带旧会员 Token |

登录使用独立账号节点池。不要因为内容线路设为海外，就把登录也发到海外内容节点。

### 10.3 当前入口

| 类型 | 当前基线 |
| --- | --- |
| 默认内容入口 | `api.manga2026.xyz` |
| 国内入口 | `api.copy202602.com` |
| 旧国内后备 | `mapi.mangacopy.com` |
| 退休并迁移 | `api.copy-manga.com`、`mapi.copy-manga.com` |

正式业务优先使用 `network2` 返回且通过语义测速的动态节点，静态入口用于发现和最后后备。

## 11. 当前接口逐项字典

### 11.1 动态节点

```text
GET /api/v3/system/network2
query:
  platform=3
auth:
  anonymous
expected:
  code=200
  results.api 可递归提取域名
  results.in_mainland 可选
```

调用者：

- 内容线路：`_refreshDynamicDomains()`。
- 账号线路：`_refreshAuthenticationDomains()`，只从国内入口请求。

失败语义：

- 发现失败不清除现有节点。
- 内容发现全空时继续使用当前/静态节点。
- 账号发现全空时回退国内静态节点。

### 11.2 节点测速

```text
GET /api/v3/search/comic
query:
  limit=1
  offset=0
  q=__copy_node_probe__
  q_type=
  platform=3
auth:
  anonymous
expected:
  HTTP 200
  code=200
  results.list is List
```

测速超时为 5 秒。延迟值为发请求到完成语义验证的总毫秒数，不只是 TCP 建连时间。

### 11.3 在线搜索

```text
GET /api/v3/search/comic
query:
  limit=20
  offset=(page-1)*20
  q=<keyword>
  q_type=
  platform=3
auth:
  anonymous
expected:
  results.list
required result fields:
  title/name
  path_word/pathWord
optional:
  uuid, author, cover, alias, brief, status, last_chapter
```

客户端搜索顺序：

1. 原始关键词；
2. 简体变体；
3. 繁体变体；
4. 第一个非空结果立即返回。

### 11.4 漫画详情

```text
GET /api/v3/comic2/<path_word>
query:
  platform=3
  in_mainland=<按实际候选节点重算>
  request_id=
auth:
  anonymous
expected:
  results.comic
  results.groups
semantic validation:
  comic.uuid 非空
  comic.path_word 非空
  comic.path_word == 请求 path_word
```

解析字段：

| 结果 | 模型 |
| --- | --- |
| `comic.uuid` | `Comic.uuid` |
| `path_word/pathWord` | `Comic.pathWord` |
| `name/title` | `Comic.title` |
| `author[].name` | `Comic.authors` |
| `cover` | `Comic.coverUrl` |
| `alias` | `Comic.alias` |
| `brief` | `Comic.brief` |
| `status.display` 或 status | `Comic.status` |
| `last_chapter.name` | `Comic.lastChapter` |
| `groups` | `ComicGroup[]` |

### 11.5 章节列表

```text
GET /api/v3/comic/<comic_path_word>/group/<group_path_word>/chapters
query:
  limit=100
  offset=0,100,200...
auth:
  anonymous
expected:
  results.total
  results.list
```

章节映射：

| 字段 | 模型 |
| --- | --- |
| `uuid` | `Chapter.uuid` |
| `name` | `Chapter.title` |
| `ordered` | `Chapter.order` |
| `size` | `Chapter.pageCount` |
| 当前组 path/name | `groupPathWord/groupName` |

当 `offset < total` 时空 list 是异常；当详情中的组 count 为 0 时不请求。

### 11.6 章节图片

候选顺序：

```text
1. /api/v3/comic/<path_word>/chapter/<chapter_uuid>
2. /api/v3/comic/<path_word>/chapter2/<chapter_uuid>
3. /api/v3/comic/<path_word>/chapter2download/<chapter_uuid>
```

三条都使用：

```text
query:
  platform=3
  in_mainland=<按候选节点重算>
  request_id=
auth:
  anonymous
expected:
  results.chapter.contents 至少一个 URL
```

兼容的 `contents` 元素：

```json
"https://cdn.example/page.jpg"
```

或：

```json
{"url": "https://cdn.example/page.jpg"}
```

任何候选返回空 URL 列表都会继续下一个候选；三条全失败才向用户汇总错误。

### 11.7 图片字节

```text
GET <完整 CDN URL>
responseType=bytes
auth:
  anonymous
headers:
  普通签名/设备头，不带会员 Token
success:
  HTTP 200 且 body 非空
```

调用者包括在线页、正式下载页和封面缓存。落盘前统一按魔数识别扩展名。

### 11.8 会员资料

```text
GET /api/v3/member/info
auth:
  Token <token>
node pool:
  authentication
expected:
  results Map
```

HTTP 401 映射为“登录已过期”。登录流程把此接口作为 Token 有效性的最终验证。

### 11.9 收藏

```text
GET /api/v3/member/collect/comics
query:
  limit=18
  offset=0,18,36...
  free_type=1
  ordering=-datetime_updated
auth:
  Token <token>
node pool:
  authentication
expected:
  results.list
  results.total
```

列表项同时兼容漫画直接位于行内，或位于 `row.comic`。

## 12. `requestResults()` 的完整决策

```text
收到业务请求
├── authenticated=true 且 Token 为空 → 立即提示登录
├── 登录或会员接口
│   └── 准备账号候选：当前账号节点 → 动态账号节点 → 国内静态节点
└── 匿名内容接口
    └── 准备内容候选：当前节点 → 动态内容节点 → 当前线路静态节点

逐候选：
├── 如果 query 有 in_mainland，按当前候选节点重写
├── 发送请求
├── 网络/接口不存在/无效 JSON → 下一个候选
├── 业务 code != 200 → 直接抛业务错误
├── validator 不通过 → 下一个候选
└── 成功 → 提升该节点并返回 results
```

因此新增接口时必须回答两个问题：

1. 这是匿名内容还是会员账号接口？
2. 什么数据才算“语义成功”？

没有 validator 的接口容易把风控页、空列表或错误漫画当成功。

## 13. 每个源码函数修改时要同步什么

| 修改函数 | 必须同步 |
| --- | --- |
| `headers()` | 固定头测试、匿名/会员 Token 测试、节点探针 |
| `loginHeaders()` | 登录请求头快照、真实登录、资料验证 |
| `loginBody()` | 固定 salt 编码向量，禁止真实密码夹具 |
| `authSignature()` | 至少一个固定时间戳精确摘要 |
| `domainsFor()` | 三种线路候选顺序测试 |
| `extractApiDomains()` | 嵌套 Map/List、无效 URL、退休域名测试 |
| `requestResults()` | 节点失败回退和业务错误不回退 |
| `_requestFromDomain()` | HTTP/code/401/JSON 错误映射 |
| `_measureDomainLatency()` | 探针语义和 Token 缺失验证 |
| `search()` | 简繁变体顺序和无结果行为 |
| `comicDetails()` | path_word 严格匹配 |
| `groupChapters()` | 100 条分页和空页回退 |
| `chapterContent()` | 三路径顺序和空图片回退 |
| `_chapterUrls()` | 字符串/对象两种元素 |
| `login()` | Token 缺失、profile 失败清 Token |
| `favorites()` | 多页、空页和 total 不一致 |
