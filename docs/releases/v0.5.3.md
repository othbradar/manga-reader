# v0.5.3+35：记住密码与收藏增量刷新

## 改动

- 登录页可记住密码并自动续期；密码只保存在系统安全存储，不进入 SQLite 或导出文件。
- 明确 401 时同一账号仅续期一次，并发共用请求；网络/风控/限流不会反复登录。
- 自动续期核验账号身份再保存令牌，不重放结果不确定的收藏 POST。
- 漫画与小说收藏默认按收藏时间检查新增，合并历史缓存，不再每次全量替换。
- 新增在前，已有条目相对顺序与非空简介保留。刷新失败/空返回不删除历史。
- 收藏菜单保留“检查全部收藏”；本机明确取消且服务器确认后才移除对应缓存。
- Android、iOS/iPadOS 与 macOS 使用同一套实现。书库索引无新增应用状态表。

旧版没有保存密码，升级后每账号需成功登录一次并勾选记住，才能自动续期。

## 本地验证

- `flutter analyze --no-pub`：无问题。
- 带本机 JXL 解码器的串行完整测试：165 项通过，2 项需手动指定真实书库/ZIP 的测试未启用。
- Mac Release 构建通过，严格代码签名校验、ZIP 与 DMG 完整性校验通过。
- Android Release APK、iOS 设备 Release 构建通过；标准/iPad 兼容 ID 的未签名 IPA 完整性检查通过。
- 续期逻辑已由本地 adapter 和安全存储测试验证；未人为使真实账号失效来制造线上 401。
