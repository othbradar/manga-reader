# 拷贝漫画阅读器 0.5.2+34

本次同步发布 Android、iOS/iPadOS、macOS。仓库及 Release 保持私有。

## 更新内容

- 新增“我的 → 切换账号”：添加账号、切换已保存账号、重新登录和移除本机登录状态。
- 每个账号独立保存安全存储中的登录令牌；账号信息、节点和当前选择只存本机 SQLite，不保存密码。
- 漫画、小说收藏按账号和书库隔离，切换时不再混用列表。旧请求及多页结果不会写入新账号缓存。
- 切换已保存账号直接恢复会话，不重复发送登录请求；添加账号失败恢复原会话，防止重复点击并发登录。
- 升级保留原收藏缓存和小说收藏，并将旧漫画收藏复制到原账号的新缓存中。
- 可携式应用数据备份保留分账号收藏，但不导出登录令牌、密码、账号列表、当前身份或设备身份。
- Android、iOS、iPadOS、macOS 共用同一实现，保留已有小说功能、JXL 支持、阅读与下载功能。

## 数据兼容

漫画库总索引的结构和保存方式不变。新增账号状态、分账号漫画收藏缓存均位于独立应用数据库。
切换、退出或移除本机账号不会删除服务器账号、收藏缓存、阅读记录、下载内容或漫画/小说文件。
覆盖升级请沿用原应用 ID 和签名，不要卸载或清除数据。
