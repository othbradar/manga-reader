# 拷贝漫画阅读器 0.5.1+33

本次同步发布 Android、iOS/iPadOS、macOS。仓库及 Release 保持私有。

## 更新内容

- 新增完整小说库：搜索、详情、收藏、TXT/插图阅读、分卷下载、来源筛选与排序。
- 漫画和小说详情页统一支持加入/取消收藏、状态显示与写后回查；取消有确认，防止重复点击。
- 支持批量收藏本地已匹配小说，跳过已收藏作品，遇到第一笔失败即停止，不删除已有收藏。
- 全部普通 API 统一到本次原版 3.0.9 逆向确认的签名、启动参数与表单编码；账号请求串行，
  不自动跨节点重放写入，匿名内容/CDN 不携带会员凭据。
- 漫画下载仍按用户要求保存匿名阅读图片为章节 ZIP；不调用原版需登录的专用下载接口。
- 保留 Android JXL 支持、短章全预载/长章附近预载、连续滚动和自由缩放修复。
- 补充详细逆向证据、排除路径、字段字典、代码入口及下一版 APK 的增量复查步骤。

## 安装包

| 文件 | 用途 |
| --- | --- |
| CopyMangaReader-v0.5.1-android.apk | Android，沿用现有应用 ID 与签名 |
| CopyMangaReader-v0.5.1-ios-unsigned.ipa | iPhone/iPad 标准 ID：com.othbradar.copymangareader |
| CopyMangaReader-v0.5.1-ipad-compat-unsigned.ipa | iPad 兼容 ID：app.plantain7005.quartz6563 |
| CopyMangaReader-v0.5.1-macos-universal.zip | 内含完整 .app，Apple Silicon / Intel |
| CopyMangaReader-v0.5.1-macos-universal.dmg | 相同 .app 的安装镜像 |
| SHA256SUMS.txt | 以上 5 个安装包的 SHA-256 |

两个 IPA 均未签名，需自行签名；沿用当前 Bundle ID，避免产生另一套数据目录。
macOS 为 ad-hoc 临时签名，未做 Developer ID 公证。安装包不含用户漫画/小说、总索引或账号数据。

## 数据兼容

漫画仍使用章节 ZIP 和原漫画表。小说新增到总索引的独立表，文件在与 `漫画` 同级的
`小说` 目录；移动整库时带上两者。阅读进度、任务、收藏缓存与设置仍在独立应用 SQLite。
外置盘原始索引继续使用本机工作副本机制；收藏操作不会改源索引或作品文件。
