# 开发、测试与发布

## 1. 环境要求

- macOS，用于同时构建 Android、iOS 和 macOS。
- Flutter/Dart，项目要求 Dart SDK `^3.12.2`。
- Xcode、iOS 13.0 以上 SDK 和当前 Flutter 支持的 macOS SDK。
- JDK 和 Android SDK；Android 最低 API 24，目标 API 36。
- 真机安装 Android 包时需要 ADB。
- 打包 IPA 不要求证书；安装到真机时需要用户自己的签名流程。

项目固定 `path_provider_android 2.2.23`。升级到 2.3.x 前要重新检查其 JNI
原生层、Gradle 配置和安卓实机外置目录行为。

## 2. 获取依赖

```bash
cd "/path/to/ipa及apk等制作/拷贝漫画阅读器"
flutter pub get
```

不要提交：

- `.dart_tool`
- `build`
- `android/local.properties`
- Gradle 缓存
- Xcode DerivedData
- APK、IPA、macOS App/DMG 和签名文件
- 原版 APK 与逆向分析产物

## 3. 发布前检查

### 3.1 格式和静态检查

```bash
dart format lib test
dart analyze --fatal-infos
```

`--fatal-infos` 保证 lint 信息也会阻止发布。

### 3.2 完整测试

```bash
flutter test --no-pub --concurrency=1
```

串行模式可避免动态节点测速测试受到其他并行测试的计时干扰。

主要测试覆盖：

- 共享漫画库只保存核心索引。
- 应用状态只进入本机 SQLite。
- 可携式应用数据备份只使用独立 SQLite，导入时正确重映射漫画库路径。
- 打开既有数据库不改其字节。
- 简繁搜索。
- 来源筛选和排序。
- ZIP 命名和自然页序。
- API 请求头、签名、节点切换、匿名令牌隔离。
- 下载进度、暂停、清理和并发限制。
- 在线阅读缓存不生成 ZIP。
- 章节下载二级页的全选与取消。
- 连续阅读锚点恢复。
- 放大后自由二维拖动和跨页。

`test/reader_page_scroll_test.dart` 用 60 页混合尺寸的真实 ZIP 测试阅读页：
将 Flutter 图片缓存上限置零，反复跨过 Sliver 缓存边界，再用 Android/iOS
触摸事件慢速上滑、下滑，逐步核对滚动距离；同时核对恢复页前一页的位置和
缩放切换解码分辨率时的高度。不要仅用同一张常驻内存图片判断跳页已修复。

### 3.3 真实只读样本

真实库和 ZIP 测试不会默认运行，避免在普通 CI 中依赖外置盘：

```bash
COPYMANGA_REAL_LIBRARY="/absolute/path/拷贝漫画总索引.db" \
  flutter test --no-pub test/real_library_test.dart

COPYMANGA_REAL_ZIP="/absolute/path/chapter.zip" \
  flutter test --no-pub test/real_zip_test.dart
```

这些测试必须使用备份或只读样本。

## 4. 版本号

`pubspec.yaml` 使用：

```yaml
version: 主版本.次版本.修订版本+构建号
```

例如：

```yaml
version: 0.4.3+28
```

- Android `versionName` 为 `0.4.3`，`versionCode` 为 `28`。
- iOS/macOS `CFBundleShortVersionString` 为 `0.4.3`，`CFBundleVersion` 为 `28`。

每次真机发布都同时增加版本号和构建号。

## 5. Android 构建与安装

构建：

```bash
flutter build apk --release --no-pub
```

输出：

```text
build/app/outputs/flutter-apk/app-release.apk
```

复制成带版本的本地发布文件：

```bash
cp build/app/outputs/flutter-apk/app-release.apk \
  "build/releases/拷贝漫画阅读器_Android_0.4.3+28.apk"
```

安装：

```bash
adb devices -l
adb -s <serial> install -r build/app/outputs/flutter-apk/app-release.apk
```

校验：

```bash
adb -s <serial> shell dumpsys package \
  com.othbradar.copymangareader | grep -E 'versionCode|versionName'
adb -s <serial> shell pidof com.othbradar.copymangareader
```

覆盖安装不会主动删除应用本机数据库或默认漫画目录。

## 6. iOS/iPadOS 构建

构建设备 Release App：

```bash
flutter build ios --release --no-codesign --no-pub
```

输出：

```text
build/ios/iphoneos/Runner.app
```

标准 Bundle ID：

```text
com.othbradar.copymangareader
```

另一个本地兼容包使用：

```text
app.plantain7005.quartz6563
```

兼容 ID 用于覆盖已经按该 ID 签名安装的 iPad 版本。两个包的代码和数据格式相同，
但不同 Bundle ID 在 iOS 看来是两个独立应用，默认数据目录也不同。

### 6.1 打包未签名 IPA

标准包：

```bash
mkdir -p build/ios/package_standard/Payload
ditto build/ios/iphoneos/Runner.app \
  build/ios/package_standard/Payload/Runner.app
ditto -c -k --sequesterRsrc --keepParent \
  build/ios/package_standard/Payload \
  build/ios/ipa/拷贝漫画阅读器_标准ID_未签名.ipa
```

兼容 ID 包需要先修改 staging 副本：

```bash
mkdir -p build/ios/package_ipad_compat/Payload
ditto build/ios/iphoneos/Runner.app \
  build/ios/package_ipad_compat/Payload/Runner.app
/usr/libexec/PlistBuddy \
  -c "Set :CFBundleIdentifier app.plantain7005.quartz6563" \
  build/ios/package_ipad_compat/Payload/Runner.app/Info.plist
ditto -c -k --sequesterRsrc --keepParent \
  build/ios/package_ipad_compat/Payload \
  build/ios/ipa/拷贝漫画阅读器_iPad兼容ID_未签名.ipa
```

不要修改源项目的 Bundle ID 来制作兼容包；只修改 staging 副本。

### 6.2 IPA 校验

```bash
unzip -t build/ios/ipa/拷贝漫画阅读器_标准ID_未签名.ipa
unzip -p build/ios/ipa/拷贝漫画阅读器_标准ID_未签名.ipa \
  Payload/Runner.app/Info.plist |
  plutil -extract CFBundleIdentifier raw -o - -
lipo -info build/ios/package_standard/Payload/Runner.app/Runner
codesign -dv build/ios/package_standard/Payload/Runner.app
```

未签名包预期：

- ZIP 无错误。
- Bundle ID 与文件名一致。
- 版本号和构建号正确。
- Runner 为 `arm64`。
- `codesign` 报告未签名。

## 7. macOS 构建与打包

构建 Release App：

```bash
flutter build macos --release --no-pub
```

输出：

```text
build/macos/Build/Products/Release/拷贝漫画阅读器.app
```

macOS Bundle ID：

```text
com.othbradar.copymangareader.macos
```

本地验证：

```bash
plutil -extract CFBundleIdentifier raw -o - \
  "build/macos/Build/Products/Release/拷贝漫画阅读器.app/Contents/Info.plist"
codesign --verify --deep --strict \
  "build/macos/Build/Products/Release/拷贝漫画阅读器.app"
open "build/macos/Build/Products/Release/拷贝漫画阅读器.app"
```

需要便于搬运的发布文件时，可同时生成 ZIP 和 DMG：

```bash
mkdir -p build/releases
ditto -c -k --sequesterRsrc --keepParent \
  "build/macos/Build/Products/Release/拷贝漫画阅读器.app" \
  "build/releases/拷贝漫画阅读器_macOS_0.4.2+27.zip"
hdiutil create -volname "拷贝漫画阅读器" \
  -srcfolder "build/macos/Build/Products/Release/拷贝漫画阅读器.app" \
  -ov -format UDZO \
  "build/releases/拷贝漫画阅读器_macOS_0.4.2+27.dmg"
```

未使用 Developer ID 公证的本地包只适合本机或受信设备测试。正式对外分发时另走
签名、公证和 stapling 流程，不要把证书或私钥提交到仓库。

推荐直接使用项目脚本完成“构建 → 最终递归签名 → 严格校验 → ZIP/DMG → 校验和”：

```bash
tool/package_macos.sh
```

Flutter 的 native-asset 增量构建有时会在 Xcode 封好外层 App 后重新签内部
`App.framework`，导致裸 `flutter build macos` 产物出现
`nested code is modified or invalid`。发布脚本会在封装前统一重签内部代码和外层
App，必须以脚本最终校验结果为准。

脚本默认使用本地临时签名。若已配置 Developer ID，可显式指定：

```bash
MACOS_SIGN_IDENTITY="Developer ID Application: 名称 (TEAMID)" \
  tool/package_macos.sh
```

## 8. 真机与桌面发布检查清单

Android、iOS/iPadOS 与 macOS 都检查：

1. 空库可以启动。
2. 默认目录可以识别现有总索引。
3. 外置目录选择器点“打开”有响应。
4. 外置索引复制到本机后漫画列表可显示。
5. 简体可搜到繁体标题。
6. 来源筛选不为空且计数合理。
7. 已下载章节读取 ZIP。
8. 未下载章节在线阅读但不生成 ZIP。
9. 章节选择页全选、取消和下载有效。
10. 下载进度、暂停、继续、失败重试和清空任务有效。
11. 连续阅读无黑边，缩放后可自由二维移动。
12. 阅读进度不会把用户反复拉回旧位置。
13. 登录、收藏、搜索和详情分别在国内/海外节点验证。
14. 深色模式和四种主题显示正常。
15. 应用重启后本机设置和下载任务仍在。
16. 导出应用数据后，漫画库根目录出现有效的可携式 SQLite。
17. 在另一平台导入后阅读位置、主题、收藏缓存和任务恢复，未完成任务保持暂停。
18. macOS 退出重开后可通过 security-scoped bookmark 恢复外置漫画库。

## 9. 本地发布包保留策略

只保留当前正式版本：

- 一个 Android APK。
- 一个标准 Bundle ID IPA。
- 一个 iPad 兼容 Bundle ID IPA。
- 一个 macOS App 的 ZIP 或 DMG；调试期间可保留未封装 `.app`。

旧 APK、旧 IPA、旧 macOS 包和 `package_*` staging 目录在确认新包校验通过后
删除。源代码、测试、文档、逆向参考资料和漫画库不属于旧发布包，不应跟着删除。

构建产物全部被 `.gitignore` 排除。GitHub 提交只包含可重现构建的源代码、资源、
平台项目、测试、工具和文档。

## 10. Git 提交

在父仓库执行：

```bash
git status --short
git add -- "拷贝漫画阅读器"
git diff --cached --stat
git diff --cached --check
git commit -m "发布拷贝漫画阅读器 0.4.2"
git push origin main
```

远程使用 SSH 时会自动使用本机 SSH agent 或 `~/.ssh` 中已配置的 RSA 密钥。
不要把私钥、账号密码、会员令牌或签名证书复制到项目目录。
