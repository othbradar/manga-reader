# 2026-10-28 会话与收藏增量

本文描述共享 Dart 实现，适用于 Android、iOS/iPadOS 和 macOS。测试使用虚构账号和
本地 HTTP adapter，不包含真实密码/Token，也不代表已完成真实服务器过期验收。

## 1. 密码记忆与自动续期

旧版仅恢复 Token，不能凭空刷新已失效的凭证。现在登录页可勾选“记住密码并自动续期”，
每账号密码单独进入系统安全存储，键为账号标识 SHA-256 派生值；不进入 SQLite、书库、
应用数据导出或日志。取消勾选、账号菜单忘记密码、移除账号都会清理对应密码，收藏不删除。
旧账号须在新版成功登录一次，才有可用于续期的密码。

`SessionController` 向 `CopyApiTransport` 注册续期回调。仅会员请求明确 401、非风控、
账号/节点未切换时触发。使用原来的签名、设备标识、登录表单和当前账号节点，不新增
私有“刷新 API”。`authenticateCredentials()` 登录后用候选 Token 查询 profile，
候选仅允许访问该 GET，不提前替换当前 Token。返回账号须与当前账号一致。

安全存储写入成功才安装新 Token；过程中账号/节点改变则不安装旧请求的结果。
逻辑 sessionRevision 与 credentialRevision 分离：同账号换 Token 不使已开始的收藏分页
变成“切换账号”，真实切换仍使旧分页失效。即使服务端重新发回同一 Token 字符串，也使用
凭证代次区分已续期，防止误判。读取密码失败或登录/profile 失败不会清空账号与收藏。

续期在串行会员请求队列外等候，否则回调里的登录/profile 会与自身互相等待。
并发 401 共用一次续期；失败记住当前会话代次，停止自动重试直到手动登录/切换。
续期成功的 GET 只重试一次。POST 收藏写入绝不自动重发，提示用户重新检查状态，防止
不确定写入重复提交。网络超时、403、429、风控提示不触发自动登录。

## 2. 收藏增量合并

原版 APK 离线证据：3.0.9 Blutter `pp.txt` 中 `collectOrdering` 映射（0x7e38）包含
`DatetimeModifierDown → -datetime_modifier`，0x7e40 是默认项；同样本 UI 有“收藏时间”。
它不同于 `-datetime_updated`（漫画更新时间）。新收藏的老漫画在更新时间排序中可能
很靠后，因此不能在该排序下见到旧 UUID 就停。没有证据支持专用 delta/cursor API，
实现仍使用已知 `/member/collect/comics`、`/member/collect/books` 分页和原版请求签名。

普通刷新使用本机已知 UUID 集合作为边界，按 `-datetime_modifier` 从 offset=0、limit=18
开始。连续两页均已知且 `已知数 + 本轮新增数 >= 服务器 total` 才允许提前停止。
初次无缓存继续到末页；缓存数量不足继续扫描。空页提前结束、重复页无进展、无 UUID、
账号切换都中止，未完成的一轮不提交缓存。局部缓存和 offset 分页不能提供服务器快照
一致性；上游并发修改/排序变更时可使用“检查全部收藏”重核，不能把启发式边界叫 delta API。

SQLite `mergeFavoriteRows()` 只处理应用本机表 `account_comic_favorites`、`favorites_cache`、
`novel_favorites`，不改漫画库索引结构/内容。按 UUID upsert，新增放在现有最小 position
之前，旧 position 不改；相同字段不重写；简介/别名/封面等空值不覆盖已有非空值。
正常刷新和手动全量检查均不删除历史，包括服务器消失/取消/暂不可见的条目。
只有本机明确取消收藏并从服务器完整列表核验不再存在时，删除该 UUID 的缓存。

“历史列表”和“已核验的服务器 UUID 集合”分开：前者用于展示，后者用于决定是否写入、
确认收藏/取消和批量收藏。写操作仍有单次提交与读回核验，不能使用增量前缀判断任意书籍
不存在。并发普通刷新与完整核验共用读任务，完整核验等待未完成的增量任务后再读取。

## 3. 回归范围

- `session_renewal_test.dart`：并发 401、死锁、同 Token、profile 验证、POST 不重放、
  风控/网络/403/429、不含密码的旧账号、续期失败不循环。
- `multi_account_test.dart`：安全存储隔离、换号/节点失效、错误身份、移除/忘记密码、
  可移植数据库不含密码/Token，以及旧账号数据保留。
- `favorite_incremental_test.dart`：100 项只读两页无变更边界、分页新增、数量缺口、
  重复页/中断拒绝提交、历史/相对顺序/简介保留、空结果不删数据、多账号隔离。
- `favorite_mutations_test.dart`：原有收藏/取消、失败不重放、批量收藏首错停止。

实机验收应使用用户授权账号，先让用户在新版成功登录并勾选保存；不要通过读取系统钥匙串
原文输出凭证，也不要为测试故意失效用户 Token 或反复触发真实登录。普通刷新前后对比
缓存条目/新增数；明确记录是否实际观察到 401 后自动续期，不得把 adapter 测试写作线上验收。
